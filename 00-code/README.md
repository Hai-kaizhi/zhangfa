# 00-code — 可选代码工作区

本目录承载当前项目的真实代码，纯文档项目可以一直保持为空。

## 使用原则

- 只有项目明确进入实现阶段后才放入代码，不复制 reference 代码或虚构实现结果。
- 代码目录结构、语言和构建方式由项目技术文档决定，不由本模板预设。
- 自动化测试、白盒报告、代码映射、CI/CD 和 Git tag 都是可选扩展。
- 文档状态以 `02-requirement-pool/` 中按节点创建的 `需求池.md` 和 `版本注册表.md` 为准，提交记录不能替代项目台账。

技术方案和规范应先在 [01-project-docs](../01-project-docs/README.md) 中形成基线。
