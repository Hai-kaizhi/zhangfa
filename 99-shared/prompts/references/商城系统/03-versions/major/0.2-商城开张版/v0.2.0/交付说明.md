## 3. 运行方式

（模拟口径）沿用既有部署形态（单机 Docker Compose：商城端与管理端静态资源、后端单体、MySQL、Nginx）；本版新增 cust_ 两表与 cms_content_slot 迁移脚本随发布执行；短信服务于本版收口（验证码通道实测，沙箱口径）；商城端首次对外发布——按 0.2 大版本灰度台阶执行上线安排（环境联调→内部演练→小额真实单→全量，全量开放前商城端仅灰度白名单可访问；灰度属上线安排，本文仅记录口径）。**范本演练说明：以上为运行方式口径描述，本版无真实可执行产物。**

## 4. 已知限制与待确认

- 已知限制（范围围栏内的刻意留白）：购物车与下单入口未出现（随 0.2.1）；内容位仅支持关联商品形态（专题落地页形态留业务确认）；搜索仅商品名匹配（扩品牌/规格名回池评估）；验证码频控与登录时长为行业惯例默认值。
- 待确认：无 PRD 歧义项；搜索扩展与专题页形态为建议回池项（已在 PRD 待议汇总）。
