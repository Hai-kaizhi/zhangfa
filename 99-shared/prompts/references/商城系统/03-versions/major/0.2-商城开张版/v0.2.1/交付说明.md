# 交付说明：v0.2.1 成交闭环版

> 本版开发交付说明：承接小版本 PRD 认领条目 R21~R31 的实现清单、验收锚自检、运行方式与已知限制。**本文档为文档范本演练**：本版不产出真实代码文件，实现清单与自检证据均按「代码已按 PRD 实现」的模拟口径编写（证据为模拟界面／接口／日志叙述），供流程范本参考；上游为模拟案例材料，模拟性质予以保留。

## 3. 运行方式

（模拟口径）沿用既有部署（单机 Docker Compose）；本版新增 trade_ 四表与 rpt_order_finance 迁移脚本随发布执行；支付渠道沙箱凭据经环境变量注入（规范）；物流跟踪经 K11 渠道查询接口（0.2 立项定案渠道）对接。上线口径：0.2 为首次对外发布与首次真实收款版本，按大版本灰度台阶执行——环境联调→内部全流程演练→小额真实单→全量开放（本版交付后进入灰度执行期，全量开放前商城端限白名单访问；灰度属上线安排，本文仅记录口径）。**范本演练说明：以上为运行方式口径描述，本版无真实可执行产物。**

## 4. 已知限制与待确认

- 已知限制（范围围栏内的刻意留白）：订单无优惠抵扣路径（0.3 接入）；退货退款与"售后中"态、库存回补（0.4，售后真空期人工过渡——退款走支付渠道商户后台、管理端订单查询核对）；评价/咨询（0.5）；收支台账查询（0.4/0.7）；发货信息提交后不可修改（更正走线下）。
- 待确认：自动流转时限（30 分钟/7 天）经营调整走 PRD 修订；发货更正入口与物流跟踪展示细节（K11 渠道定案后细化）。
