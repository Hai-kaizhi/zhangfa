# 交付说明：v0.1.1 商品货架版

> 本版开发交付说明：承接小版本 PRD 认领条目 R8~R14 的实现清单、验收锚自检、运行方式与已知限制。**本文档为文档范本演练**：本版不产出真实代码文件，实现清单与自检证据均按「代码已按 PRD 实现」的模拟口径编写（证据为模拟界面／接口／日志叙述），供流程范本参考；上游为模拟案例材料，模拟性质予以保留。

## 1. 实现清单（条目｜代码位置｜实现要点）

| 条目 | 代码位置（模拟口径） | 实现要点 |
|---|---|---|
| R8 商品建档与编辑 | server 端 `com.haowu.product` 商品服务；管理端 `apps/admin-web` 商品管理＞新建/编辑表单 | 商品档案与 SKU 行编辑（一对象两表 prod_product＋prod_sku）；保存一律草稿态；已上架商品编辑即时复检完备性并拦截；无分类时建档拦截并引导 |
| R9 ◆ 商品上下架 | server 端商品状态处置；管理端列表与档案页操作 | 完备性四要件校验（名称/分类/至少一规格与售价/库存台账就绪）缺口清单反馈；上下架二次确认；动作留痕；状态前置条件防重复操作 |
| R10 商品查询（管理端路径） | server 端商品检索接口；管理端商品列表页 | 名称模糊/分类/品牌/状态组合筛选；分页默认 20 条；状态标签三色（草稿＝辅助、已上架＝成功、已下架＝危险）；空态两种 |
| R11 分类树增删改查 | server 端分类服务；管理端分类管理页 | 父子树（层级≤3）；同父级同名唯一；父分类防环校验（自身/后代拦截）；被引用删除拦截；含子分类连带确认 |
| R12 品牌增删改查 | server 端品牌服务；管理端品牌管理页 | 品牌名全局唯一；介绍 ≤200 字符；品牌图经图片资源（biz_type=brand）；被引用删除拦截 |
| R13 库存设置与调整 | server 端库存台账；商品档案库存分区 | 按 SKU 建行（档案首次保存含 SKU 时创建，数量 0）；非负整数校验上限 9999999；调整留痕（前后值/操作者/时间/原因）只增；locked_qty 字段就绪恒 0（先行基座） |
| R14 图片上传与关联 | server 端图片能力（公共基座挂商品模块）；档案图集组件 | JPG/PNG/WebP、≤5MB 校验；biz_type＋biz_id 关联（product/brand）；每商品 ≤9 张、封面唯一；外站转存；取消关联软删除 |
| 数据层 | 建表 prod_product／prod_sku／prod_category／prod_brand／prod_stock／sys_image_asset（落库字段逐字按术语表 v0.1.1 商品域登记行） | 审计三字段齐备；prod_stock.sku_id 唯一（一 SKU 一台账行）；sys_image_asset 按 biz_type＋biz_id 关联 |

## 3. 运行方式

（模拟口径）沿用 v0.1.0 部署形态：单机 Docker Compose（管理端静态资源、后端单体、MySQL、Nginx）；本版新增 prod_ 五表与 sys_image_asset 的迁移脚本随发布执行；图片静态服务经 Nginx 指向本地存储目录；登录与授权沿用 v0.1.0（运营角色挂入 prod 域能力点后即可见商品管理菜单）。**范本演练说明：以上为运行方式口径描述，本版无真实可执行产物。**

## 4. 已知限制与待确认
