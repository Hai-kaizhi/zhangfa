## 3. 运行方式

（模拟口径）沿用既有部署（单机 Docker Compose）；本版新增 mkt_ 三表迁移脚本随发布执行；档期调度任务随单体调度组件注册（任务名独立于内容位档期任务，规范）。上线口径：本版为纯管理端与商城端新增页面，不引入新的资金方向，沿用 0.2 灰度状态（全量开放决策不影响本版发布）；促销规则为本版立项定案口径（0.3 大版本 PRD 1 章）。**范本演练说明：以上为运行方式口径描述，本版无真实可执行产物。**
