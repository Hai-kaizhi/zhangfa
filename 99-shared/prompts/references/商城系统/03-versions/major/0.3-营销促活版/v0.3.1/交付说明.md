## 3. 运行方式

（模拟口径）沿用既有部署（单机 Docker Compose）；本版仅 trade_order 增列迁移脚本随发布执行（discount_amount）；无新任务与新外部依赖。上线口径：促销成交引入新的金额计算路径（券抵扣与秒杀价）但不引入新资金方向，沿用 0.2 灰度状态；建议灰度期内小额真实单覆盖用券与秒杀各一笔（演练口径，属上线安排）。**范本演练说明：以上为运行方式口径描述，本版无真实可执行产物。**
