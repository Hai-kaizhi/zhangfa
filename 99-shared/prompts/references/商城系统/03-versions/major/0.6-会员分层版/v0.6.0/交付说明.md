# 交付说明：v0.6.0

> 定位：v0.6.0 等级分层版的开发交付说明——承接本版 PRD 认领条目（R59 等级模板增删改查、R60 ◆ 等级归属重算、R61 顾客查询与详情（分层画像）），按「代码已按 PRD 实现」口径编写；本项目为模拟示范案例（文档范本演练），无真实代码产物，证据为模拟口径。

## 1. 实现清单（条目｜代码位置｜实现要点）

| 条目 | 代码位置 | 实现要点 |
|---|---|---|
| R59 等级模板增删改查 | 服务端·顾客模块分包（等级模板服务）＋管理端·会员等级管理页 | 新表 `cust_member_level`：`level_name`、`threshold_amount`、`benefit_desc`、`sort_order`，落库字段与术语表 v0.6.0 登记行逐字一致；名称全局唯一、门槛全局唯一、默认级（门槛 0）不可删且门槛不可改非 0；被归属引用不可删；软删除留痕 |
| R60 ◆ 等级归属重算 | 服务端·顾客模块分包（归属重算服务＋定时任务）＋管理端·全量重算入口 | 累计实付＝已完成订单实收合计−已完结退货退款合计（派生取数不落字段）；三触发（每日定期全量、订单完成／退款完结事件增量、运营手动全量）；门槛从高到低取最高满足档、未达任何门槛归默认级；更新 `member_level_id` 留痕、幂等（无变化不产生记录）、任务可重入 |
| R61 顾客查询与详情（分层画像） | 管理端·顾客管理＋服务端·顾客模块分包（检索与画像查询） | 手机号精确／昵称模糊／等级下拉组合检索；列表脱敏手机号；详情画像＝等级归属＋距下一等级进度＋账号状态＋交易沉淀摘要（与重算同口径派生）；三角色只读、能力点控制（D4） |

范围外零实现：账号冻结与恢复（随 v0.6.1）、权益自动兑现（暂缓清单）、积分任务等成长体系、统计报表（0.7）。

## 3. 运行方式

按「代码已按 PRD 实现」口径（模拟）：服务端随顾客模块分包部署（单服务形态）；管理端（PC Web）以运营人员身份走「会员等级」配置与全量重算、以运营／客服／管理者身份走「顾客管理」检索与画像；商城端（移动 Web）会员登录会员中心查看等级与权益卡。验收用数据＝若干不同累计实付的存量顾客（覆盖默认／白银／黄金三档与降级场景）、既有完成订单与已完结退货单。本演练未产出可运行包，操作路径以本版 PRD 第 4 章各条目交互与流程为准。
