# 商城系统（好物商城）· 提示词体系示范项目

> 本目录是提示词体系示范项目「好物商城」（自营零售电商，商城端＋管理端）的完整项目目录：项目级基线在 `01-project-docs/`，需求台账与版本产出在 `02-requirement-pool/`、`03-versions/`、`04-workspace/`。模拟性质予以保留。

## 目录结构

| 目录 | 内容 |
|---|---|
| `00-inputs/` | 原始需求（立项输入材料） |
| `01-project-docs/` | 项目级基线：概念、PRD、技术、术语表、开发规范、UI 脚本、模块设计（一主八分）、产品路线图 |
| `02-requirement-pool/` | 需求池（活跃台账 4 条：复盘期单条入池 M01~M04＋发布归档 66 条）、版本注册表、发布日志 |
| `03-versions/major/` | 大版本目录：0.1-开张筹备版、0.2-商城开张版、0.3-营销促活版、0.4-售后收口版、0.5-服务体验版、0.6-会员分层版、0.7-经营复盘版（各小版本全归档，路线图完成） |
| `04-workspace/` | 小版本开发工作区（发布后清理，README 留归档指路） |
