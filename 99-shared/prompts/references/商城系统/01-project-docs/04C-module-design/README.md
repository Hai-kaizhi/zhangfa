# 04C 模块设计（项目）导航

> 先读 [04C-00-模块总览.md](./04C-00-模块总览.md) 了解模块划分、对象归属与跨模块关系，再按需进入各模块分文档；分文档是总览对应小节的同构放大（六节固定：职责与边界→对象→功能→状态→对外契约→待议）。上游为模拟案例材料，本目录为模拟案例评审稿。

| 文档 | 包含模块与主要内容 |
|---|---|
| [04C-00-模块总览.md](./04C-00-模块总览.md) | 八模块划分、23 对象归属、共享对象（◇）、跨模块关系图与协作约束表 |
| [04C-权限.md](./04C-权限.md) | 权限模块：管理端账号、角色；登录鉴权、授权、个人设置自助面 |
| [04C-顾客.md](./04C-顾客.md) | 顾客模块：顾客账号、收货地址、会员等级；个人中心自助面认领 |
| [04C-商品.md](./04C-商品.md) | 商品模块：商品、分类、品牌、库存、评价、图片资源；上下架与库存变动契约 |
| [04C-交易.md](./04C-交易.md) | 交易模块：购物车、订单、订单项、支付单、退货单；五个 ◆ 复杂功能（下单/回调/取消/自动流转/售后） |
| [04C-营销.md](./04C-营销.md) | 营销模块：优惠券、持有记录、秒杀活动；核销退回与秒杀联动契约 |
| [04C-内容.md](./04C-内容.md) | 内容模块：内容位、帮助文章；上下线与档期执行 |
| [04C-服务.md](./04C-服务.md) | 服务模块：咨询工单；答复流转与重开 |
| [04C-报表.md](./04C-报表.md) | 报表模块：订单收支台账、统计报表视图（只读分析类） |

业务模块与技术文档分包一一对应（公共基座分包为横切技术能力，以开发规范机制条款承载，不设业务模块）。模块边界变更时先修订《模块总览》再同步受影响分文档；维护记录见各文档待议节与项目变更台账。
