# 术语表（项目）：好物商城

> 全链业务命名的**单一可信源**：主体与端、角色、业务对象（含落库表名）、状态枚举、编码契约、称谓、关键落库字段以本表为准；各层文档与代码逐字沿用，禁止同义改写。新名定名即登记本表；改名必须走文末变更记录并同步全部受影响文档。上游为模拟案例材料，模拟性质予以保留。

## 1. 主体与端

| 名称 | 类别 | 定义 | 首见文档 |
|---|---|---|---|
| 买家 | 主体（用户主体） | 最终使用产品、完成购买与售后的顾客 | 概念文档 |
| 经营团队 | 主体（经营主体） | 对经营结果负责的自营商家，内部按岗位分角色 | 概念文档 |
| 商城端 | 端 | 买家侧手机商城（移动 Web 应用） | 概念文档 |
| 管理端 | 端 | 内部 PC 网页管理后台 | 概念文档 |

## 2. 角色

| 名称 | 所属主体 | 职责模板 | 首见文档 |
|---|---|---|---|
| 买家 | 买家 | 自主完成浏览、选购、支付、收货、评价与售后申请 | 概念文档 |
| 运营人员 | 经营团队 | 上架商品、维护分类品牌规格库存、排内容位、发优惠券、做秒杀、管会员等级 | 概念文档 |
| 订单履约人员 | 经营团队 | 接单、发货、登记物流、跟进订单履约 | 概念文档 |
| 客服人员 | 经营团队 | 审核退货退款、答复咨询 | 概念文档 |
| 管理者 | 经营团队 | 看统计报表、管理账号与权限 | 概念文档 |

## 4. 状态枚举（界面中文 → 落库值）

| 对象 | 状态（中文 → 落库值；加 ★ 为终态） |
|---|---|
| 顾客账号 | 正常 `NORMAL`；冻结 `FROZEN`；注销 ★ `CANCELLED` |
| 管理端账号 | 正常 `NORMAL`；停用 `DISABLED` |
| 商品 | 草稿 `DRAFT`；已上架 `ON_SALE`；已下架 `OFF_SALE`（可重新上架，非终态） |
| 订单 | 待支付 `PENDING_PAY`；待发货 `PENDING_SHIP`；已发货 `SHIPPED`；已完成 ★ `COMPLETED`；已取消 ★ `CANCELLED`；售后中 `AFTER_SALE`（完结回已完成） |
| 支付单 | 待支付 `PENDING`；支付成功 ★ `PAID`；已关闭 ★ `CLOSED`；已退款 ★ `REFUNDED` |
| 退货单 | 待审核 `PENDING_REVIEW`；待退货 `PENDING_RETURN`；退款完成 ★ `REFUNDED`；已拒绝 ★ `REJECTED`；已取消 ★ `CANCELLED` |
| 优惠券持有记录 | 未使用 `UNUSED`；已使用 ★ `USED`（订单取消退回，回未使用）；已过期 ★ `EXPIRED` |
| 秒杀活动 | 待开始 `PENDING`；进行中 `ACTIVE`；已结束 ★ `ENDED` |
| 咨询工单 | 待响应 `PENDING`；处理中 `PROCESSING`；已完结 ★ `CLOSED`（追问重开，回处理中） |

## 5. 编码契约

| 项 | 契约 |
|---|---|
| 订单号 | 前缀 `ORD` + 日期（yyyyMMdd）+ 6 位当日序列，如 `ORD20260920000123`；落库字段 `order_no` |
| 支付单号 | 前缀 `PAY` + 同上规则；落库字段 `payment_no` |
| 退货单号 | 前缀 `RET` + 同上规则；落库字段 `return_no` |
| 咨询工单号 | 前缀 `TIC` + 同上规则；落库字段 `ticket_no` |
| 金额 | 一律整数、单位**分**（对应技术决策 K10）；金额字段后缀 `_amount` |
| 状态字段 | 统一字段名 `status`，取值为第 4 节落库值字符串 |
| 主键 | 统一 `id`（自增整型） |
| 关联外键 | `<对象>_id`，如 `customer_id`、`product_id`；跨单据关联用业务单号（如 `order_no`） |
| 时间字段 | 创建 `created_at`、更新 `updated_at`，时间点语义字段后缀 `_at` |
| 逻辑删除 | `deleted`（0 否 / 1 是）；订单、支付单、退货单、订单收支记录不做删除 |
| 快照字段 | 订单项冗余的成交时点字段后缀 `_snapshot`（如 `product_name_snapshot`） |
| 图片关联 | 统一经 `sys_image_asset` 的 `biz_type` + `biz_id` 关联，不存裸路径 |
| 订单收支记录类型 | 收入 `INCOME`（支付成功）；支出 `EXPENSE`（售后退款）；冲正 `REVERSAL`（交易事实修正的台账对冲，金额取反、关联被冲正单号，只追加） |

| 场景 | 统一称谓 | 说明 |

| 沟通与文档中对 C 端使用者 | 买家 | 不混用"用户/客户/消费者" |
