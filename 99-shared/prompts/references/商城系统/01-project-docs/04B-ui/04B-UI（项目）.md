# 好物商城 · UI 生图脚本

> 本文档是「UI 生图脚本」：提示词由 GPT 在对话中分析资料后自己撰写，本文档只提供资料清单与分步话术；主流程按"GPT 同一对话＋GPT-image"编写。上游为模拟案例材料，模拟性质予以保留。

## 0. 准备：给 GPT 哪些资料

| 资料 | 位置 | 必给或可选 |
|---|---|---|
| 概念文档（项目） | `01-project-docs/01-concept/01-概念文档（项目）.md` | 必给（调性源头） |
| PRD（项目） | `01-project-docs/02-prd/02-PRD（项目）.md` | 必给（功能全景与硬约束源头） |
| 术语表 | `01-project-docs/术语表.md` | 必给（界面称谓与状态名的唯一来源） |
| 原始需求 | `00-inputs/01-原始需求.md` | 可选（背景补充） |
| 技术文档（项目） | `01-project-docs/03-tech-doc/03-技术文档（项目）.md` | 可选（组件库选型） |

新建一个 GPT 对话，一次性把"必给"资料粘贴给 GPT，然后按第 1 步开始。

## 1. 第一步话术：让 GPT 产出主页（第一张图）的生图提示词

> 我要为一个名为「好物商城」的自营零售电商系统生成 UI 设计图。请先通读我提供的全部资料，然后**只做一件事：撰写第一张图——商城端（手机端，竖屏 9:19.5）首页的生图提示词。先只输出提示词，不要生成图片。**
>
> 撰写提示词时必须遵循以下风格锚定（不得偏离）：
> - **色板（精确 hex，为本项目品牌色唯一来源）**：主色 `#DA3A2B`（暖正红，用于主行动按钮、价格强调、选中态，业界自营品质电商多用正红系，如京东红 `#E1251B`、严选红 `#DD1A21` 同族）；营销强调色 `#FF6A00`（仅用于秒杀/促销标签，淘宝橙 `#FF5000` 同族）；成功 `#2FA65A`、警告 `#E8A33D`、危险 `#D85555`；中性色阶：文字主 `#1F2329`、次级 `#4E5969`、辅助 `#86909C`、分隔 `#C9CDD4`、页面底 `#F2F3F5`、卡片 `#FFFFFF`。整体白底为主、主色点缀，克制清爽。
> - **字体与组件形态**：系统默认无衬线中文字体；卡片式布局、圆角 8px、轻投影；移动端底部标签栏导航（首页/分类/购物车/会员）。
> - **通用禁止**：界面文字全部为简体中文；不得出现"平台、商家入驻、多商户、分账"等字样或概念（本产品为单一卖方自营）；不得出现英文界面文案、第三方品牌标识、支付渠道以外的金融元素；人像与插画仅作占位不出现真实品牌。
> - **首页必须元素**：顶部搜索框、轮播推荐位、秒杀活动区块、商品分类快捷入口、商品瀑布流卡片（含价格与"已上架"可售商品样式）。
> - **称谓纪律**：C 端登录后使用者界面称"会员"，状态名（如订单状态）严格按我提供的术语表中文原文。
>
> 提示词结构要求：先一段总述（风格与布局意图），再分区块描述（从上到下），最后列出色彩与文字约束。输出后停下来等我确认。

## 2. 第二步：生成并迭代主页

确认提示词无误后，发送：

> 请用这张首页提示词生成图片（竖屏手机端首页）。

迭代方法：对不满意的局部直接描述改哪里（如"顶部搜索框改圆角胶囊形，保持其余不变"），让 GPT 修改提示词后重新生成；**满意的那一版首页即全局风格基准**，后续所有图都向它看齐。色彩如需微调，改附 A 色值表并同步第一步话术中的 hex。

## 3. 第三步话术：规划其余图片并逐张撰写提示词

> 首页风格已定（以上一张满意图为基准）。请基于资料规划其余 UI 图片，**先输出完整清单（说明总数与每张的作用），经我确认后再逐张输出提示词**。规划必须满足以下覆盖要求：
>
> - **商城端（手机竖屏 9:19.5）**：商品搜索与结果页、商品详情（含规格选择）、购物车、订单确认与支付、订单列表与订单详情（含各订单状态标记）、售后申请（退货退款）、会员中心（个人资料、收货地址簿、持券）、在线咨询、帮助中心。
> - **管理端（PC 横屏 16:9，左侧导航＋内容区布局）**：登录页、商品管理（列表与编辑）、订单管理（列表与发货处理）、售后处理（退货审核）、促销管理（优惠券与秒杀）、运营内容配置（内容位）、权限管理（账号与角色）、统计报表、订单收支台账。
> - **状态覆盖**：核心列表页各配一张空态或异常态示意（购物车空、订单为空、报表无数据等，由你判断最必要的几张并说明）。
> - **界面要点（必须体现在相关图中）**：订单与售后状态用术语表中文状态名；售罄/失效商品有明显标记；管理端各页面体现"按角色仅见授权菜单"；价格展示为人民币元；秒杀区块用营销强调色 `#FF6A00` 区别于日常红。
> - 通用禁止与称谓纪律同第一张图。风格、色板、组件形态一律向已定基准看齐。

## 4. 第四步：批量生成

清单确认后，发送：

> 按清单顺序逐张生成图片，每张生成后停顿，等我记录后再继续下一张。

单张迭代方法：同第 2 步，逐张局部修正；整批完成后如出现风格漂移，回引首页基准图让 GPT 校正后重生成该张。

## 5. 收尾：回填归档

全部图片满意后，把每张图的信息回填到本文档附 B（图/内容说明/与基准的偏差/色彩微调）；如做了色彩微调，同步更新附 A 色值表与第一步话术中的 hex，保持"文档色值＝品牌色唯一来源"。

## 附注 其他生图模型的差异

使用即梦等无对话记忆的生图模型时：把第 1 步话术连同资料摘要、风格锚定全文一并放入提示词前置段落；每次生成单张图时重复附上风格锚定与该图提示词；迭代以"新对话＋完整提示词"方式进行，回填流程相同。
