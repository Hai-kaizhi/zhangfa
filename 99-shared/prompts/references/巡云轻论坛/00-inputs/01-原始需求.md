# 原始需求

我们要做一个自建自营的社区论坛，把「论坛讨论」和「悬赏问答」放在同一个站里：日常话题、经验交流在论坛里聊；遇到卡住的具体问题就发悬赏问答，谁答得好谁拿悬赏。站点自建自营，账号、内容、数据都握在自己手里，不依赖第三方平台。

给谁用：站长与运营人员，负责拉人、定规则、管内容；版主与内容管理员，负责审核与治理；普通访客与会员，来看帖、搜答案、提问和回帖；以及愿意长期答题、靠积分和声望积累身份的老手。

解决什么问题：讨论散落在聊天群里，搜不到也留不下；提问常常没人认真答，会答的人没有回报；社区内容质量参差，运营方缺治理抓手；新人来了留不住，缺成长和激励。

核心场景与业务闭环：
- 讨论闭环：注册登录 → 进板块看帖 → 发话题、评论回复 → 点赞收藏 → 内容被更多人看到 → 继续生产内容。
- 问答闭环：提问并追加补充 → 设悬赏 → 会员作答、补充 → 提问人采纳最佳答案 → 悬赏结算给答题人，优质问答沉淀为可搜索的答案库。
- 成长闭环：注册 → 发帖、回帖、被采纳 → 涨积分、升等级 → 解锁更多可见内容与权限。
- 治理闭环：话题、问题、回答先审后发 → 举报与敏感词兜底 → 违规处置（删帖、禁言、封号）。

范围与偏好：
- 端：必须有电脑端网页和手机端网页，同一站点自适应；前台内容要能被搜索引擎收录，方便站外引流；另有面向运营与版主的管理后台。
- 论坛必备：板块与标签、发帖与编辑、评论回复、点赞收藏、搜索、按等级/积分/回复可见的权限控制、审核。
- 问答必备：提问与追加、回答与回复、悬赏、采纳最佳答案、审核、搜索。
- 会员必备：注册登录、资料与头像、等级积分、私信与通知提醒、关注与粉丝。
- 运营与治理必备：内容审核、举报、敏感词、板块与用户管理、全站设置、浏览量统计。
- 本期明确不做：不做原生 App 和小程序，先把网页端做扎实；不做真实资金交易（在线支付、现金悬赏、红包、会员卡、平台分成），悬赏先用积分；不做 AI 问答助手、直播、短视频等扩展玩法。
