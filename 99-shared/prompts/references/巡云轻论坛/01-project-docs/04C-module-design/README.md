# 模块设计（项目）

先读 [04C-00-模块总览.md](./04C-00-模块总览.md)，再按需要进入各模块详情文档；详情与总览的对应小节同构，是从总览某模块小节的无缝放大。

| 文档 | 包含的模块与主要内容 |
|---|---|
| [04C-00-模块总览.md](./04C-00-模块总览.md) | 项目结构（模块与对象）、九个模块的职责与对象归属、跨模块关系（对象关联表与协作约束表） |
| [04C-会员与权限模块.md](./04C-会员与权限模块.md) | 会员账号、管理端账号、管理端角色；注册登录、个人中心、账号状态、账号权限与角色授权、会员查询与维护（运营侧） |
| [04C-板块与标签模块.md](./04C-板块与标签模块.md) | 板块、标签；站点结构的建立维护与前台入口 |
| [04C-话题模块.md](./04C-话题模块.md) | 话题、评论；发帖、编辑重提、删除、可见权限、评论互动与运营侧内容查询与维护 |
| [04C-问答与悬赏模块.md](./04C-问答与悬赏模块.md) | 问题、答案、悬赏；提问与追加、作答、采纳结算、到期退回、问答列表与搜索、运营侧内容查询与维护 |
| [04C-互动模块.md](./04C-互动模块.md) | 点赞、收藏、关注；轻量关系的建立解除与个人侧列表 |
| [04C-消息模块.md](./04C-消息模块.md) | 私信、通知提醒；站内往来与结果送达 |
| [04C-审核与治理模块.md](./04C-审核与治理模块.md) | 审核记录、举报、敏感词；内容审核、举报处置与违规处置 |
| [04C-成长模块.md](./04C-成长模块.md) | 会员等级、积分账户、积分流水；账本记账与等级判定 |
| [04C-运营与设置模块.md](./04C-运营与设置模块.md) | 全站设置、浏览量、运营内容；站点参数与规则配置、运营内容维护与热度统计 |

本模块集与技术文档《系统构成》的九个分包一一对应，无聚合与拆分；本目录只覆盖项目级机制设计，页面交互、时限阈值与授权到人留小版本 PRD，字段与接口签名留版本级开发。

维护记录：变更登记见项目《术语表》的变更记录与各文档的待议末节；新增模块或调整对象归属时同步更新总览与相关详情。
