# 巡云轻论坛 — 自建自营的社区论坛（论坛讨论＋悬赏问答）

把「论坛讨论」和「悬赏问答」放进同一个站：日常话题、经验交流在论坛里聊，遇到卡住的具体问题就发悬赏问答，谁答得好谁拿悬赏；账号、内容、数据由经营方自己掌握，不依赖第三方平台。前台为电脑端网页与手机端网页（同一站点自适应、内容可被搜索引擎收录），另有面向站长、运营人员与版主的管理后台。本期不做原生 App 与小程序、不做真实资金交易、不做 AI 问答助手与直播短视频。

> 口径说明：本项目为模拟案例，上游为模拟案例材料，模拟性质予以保留；各文档中的决策状态以文内标注为准。
