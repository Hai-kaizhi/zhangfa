# 交付说明：v0.1.0

> 定位：本版开发交付说明——承接《PRD（小版本）v0.1.0》认领条目 R1～R12 的实现清单、验收锚自检、运行方式与已知限制；本交付为**文档范本演练**（不产出代码文件），实现位置为按技术文档模块划分的约定落位、验收证据为模拟演练证据；上游为模拟案例材料，模拟性质予以保留。

## 1. 实现清单（条目｜代码位置｜实现要点）

| 条目 | 代码位置 | 实现要点 |
|---|---|---|
| R1 注册 | 单体应用·会员与权限模块（会员身份服务）；前台页面工程·注册页 | 账号名／密码／确认密码三项表单；账号名 4～32 位字母开头规则与全局唯一（不区分大小写）；密码 ≥8 位含字母数字；成功建立正常状态会员账号并自动登录，默认昵称＝账号名、默认头像兜底；凭据仅落 password_hash |
| R2 登录 | 单体应用·会员与权限模块（统一鉴权组件）；前台页面工程·登录页；管理后台工程·登录页 | 前台与管理后台两入口共用统一鉴权；凭据错误统一提示不区分账号是否存在；连续失败 5 次锁定 10 分钟；停用账号登录拒绝 |
| R3 退出 | 单体应用·会员与权限模块（会话管理）；前台与管理后台页头 | 二次确认后销毁会话并跳转登录页；会话 30 天不活动过期等效退出；已过期时退出幂等 |
| R4 密码修改与重置 | 单体应用·会员与权限模块（凭据服务）；前台·个人资料页 | 原密码校验＋新密码强度与一致性校验；新密码不得与原密码相同；成功后更新 password_hash 并销毁该账号全部登录态 |
| R5 资料与头像维护 | 单体应用·会员与权限模块（资料服务）；前台·个人资料页 | 昵称 2～24 字符；头像 jpg／png／webp ≤2MB 白名单校验；保存后即时回显且重登后仍为新值 |
| R6 账号开通 | 单体应用·会员与权限模块（管理端账号服务）；管理后台工程·账号与角色管理页 | 账号名规则同注册；至少选择一个角色（多选）；系统生成 12 位一次性初始密码仅结果页展示一次；开通写入操作留痕 |
| R7 账号编辑 | 单体应用·会员与权限模块（管理端账号服务）；管理后台·账号编辑页 | 账号名只读不可改；备注 ≤50 字；保存后列表与详情即时显示新值；编辑写入操作留痕 |
| R8 账号停用与启用 | 单体应用·会员与权限模块（账号状态服务）；管理后台·账号列表 | 停用后该账号登录拒绝且既有登录态失效；启用恢复；重复停用幂等；不能停用当前登录账号；动作写入操作留痕 |
| R9 账号注销 | 单体应用·会员与权限模块（账号状态服务）；管理后台·账号列表 | 仅停用中账号可注销；二次确认显示账号名与编号并要求输入「注销」；注销进入停用终态不可再启用；写入操作留痕 |
| R10 角色定义与调整 | 单体应用·会员与权限模块（角色服务与能力点判定组件）；管理后台·角色页 | 角色名 2～24 字符全局唯一；能力点集合以功能名命名、至少一项；调整后账号下次进入按新集合渲染入口并校验接口；变更写入操作留痕 |
| R11 角色分配 ◆ | 单体应用·会员与权限模块（角色服务）；管理后台·账号编辑页 | admin_account_role 关联表承载多对多（admin_id＋role_id 联合唯一）；能力点判定取各角色并集，页面入口与接口校验同源；分配与调整写入操作留痕 |
| R12 管理端资料与凭据重置 | 单体应用·会员与权限模块（个人设置服务）；管理后台·个人设置页 | 三类角色共用；自身备注与凭据重置；重置后旧登录态失效；越权修改他人被接口拦截 |

数据落库：member_account、admin_account、admin_role、admin_account_role 四表按 PRD 第 5 章字段表与术语表命名建表；登录态为服务端会话（机制态）；操作留痕落 operation_log（机制态，本版只落痕迹不建查询面）。同事务契约：账号状态变更与登录态失效、角色分配与能力点判定刷新、留痕与业务变更同事务实现。

## 3. 运行方式

- 服务端：单体应用（Spring Boot），配置 application.yml 数据库连接后以 Maven 启动；部署初始化内置站长初始账号 admin（部署时设定初始密码，首次登录强制修改）。
- 前台：电脑端网页与手机端网页为同一站点响应式页面，随服务端渲染输出。
- 管理后台：独立前端工程（Vue＋Element Plus）构建产物由反向代理服务；统一鉴权会话与前台同源。
