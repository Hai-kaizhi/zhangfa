## 1. 实现清单（条目｜代码位置｜实现要点）

| 条目 | 代码位置 | 实现要点 |
|---|---|---|
| R13 板块新增 | 单体应用·板块与标签模块（板块服务）；管理后台工程·板块与标签管理页 | 板块名 2～24 字符全局唯一（不区分大小写）＋说明 ≤100 字校验；排序值默认＝当前最大值＋10 追加末位；新增后状态为启用 |
| R14 板块编辑 | 单体应用·板块与标签模块（板块服务）；管理后台·板块编辑 | 名称与说明可改，唯一性校验排除自身；保存后列表与详情即时回显；编辑写入操作留痕 |
| R15 板块排序 | 单体应用·板块与标签模块（板块服务）；管理后台·板块列表 | 拖拽与排序值输入两种方式，批量保存；排序值 1～9999，同值按创建时间稳定排序；变更写入操作留痕 |
| R16 板块停用与启用 | 单体应用·板块与标签模块（板块状态服务）；管理后台·板块列表 | 停用确认弹窗；状态标记启用↔停用；对新增内容的提交拦截校验独立成校验服务（先行就绪，0.2 接入）；动作写入操作留痕 |
| R17 板块删除 ◆ | 单体应用·板块与标签模块（板块状态服务）；管理后台·板块列表 | 前置校验板块下无内容（本版恒通过，校验逻辑就绪）；二次确认输入「删除」二字；删除不可恢复并写入操作留痕 |

| R21 站点信息维护 | 单体应用·运营与设置模块（全站设置服务）；管理后台·全站设置页 | 站点名 2～30 字符、说明 ≤200 字；键值落库（site_name、site_description）；保存后全站即时生效并写入操作留痕（含前后值） |
| R22 审核策略配置 ◆ | 单体应用·运营与设置模块（全站设置服务）；管理后台·全站设置页 | 话题／问题／答案／评论四类多选（默认全选）；与当前生效值相同则幂等返回、不产生新变更记录；变更写入操作留痕（含前后值）；统一读取接口供 0.2 内容审核接入（先行基座） |

数据落库：board、tag、site_setting 三表按 PRD 第 5 章字段表与术语表命名建表（board_no、tag_no 对外编号终身不变）；操作留痕沿用 v0.1.0 的 operation_log（机制态）。同事务契约：状态与排序变更连同留痕同事务；审核策略保存与幂等判定、留痕同事务。

## 3. 运行方式

- 服务端：单体应用（Spring Boot）沿用 v0.1.0 部署形态，配置 application.yml 数据库连接后以 Maven 启动；本版新增三张表的初始化迁移脚本随应用执行。
- 管理后台：独立前端工程（Vue＋Element Plus）构建产物由反向代理服务；「板块与标签管理」「全站设置」「设置查看」入口按能力点渲染（能力点清单由站长在角色定义中追加勾选）。
- 站点名展示：管理后台顶栏与后续前台页面统一读取 site_setting 的 site_name 配置。
