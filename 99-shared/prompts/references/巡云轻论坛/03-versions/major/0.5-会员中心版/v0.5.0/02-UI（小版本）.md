## 1. 第一步话术：让 GPT 产出本版核心界面的生图提示词

```text
你是资深 UI 设计师。我已提供《PRD（小版本）v0.5.0》《UI（项目）生图脚本》《术语表（项目）》三份资料（如另附项目 PRD 与技术文档一并参考）。

请先只分析、只输出一段生图提示词，不要生成图片。

一、产品与主端
- 产品：自建自营的社区论坛「巡云轻论坛」，本版为个人中心与注销版本（个人中心聚合面、等级权益配置、会员注销）。
- 第一张图＝本版核心界面：电脑端网页（画布 1440×900）的「个人中心首页」——以我的内容四类分组为主体、左侧聚合导航，本版信息量最大的自助管理面。
- 界面文字全部为简体中文，用词逐字取自《术语表（项目）》。

二、核心界面必须出现的元素（缺一不可）
- 顶部：站点名「巡云轻论坛」、板块导航、站内搜索入口、消息中心入口（未读角标）。
- 左侧聚合导航：我的内容（当前选中）、我的收藏、我的点赞、我的积分与等级、我的私信与通知提醒、我的资料与凭据；导航底部为「注销账号」入口（危险色文字链）。
- 主区「我的内容」：话题、评论、问题、答案四个分组标签（当前「话题」）；列表行含标题、类型、发布时间与状态标识——「已公开」（成功色胶囊）、「待审核」（警示色胶囊）、「已驳回」（危险色胶囊）各至少一条；已驳同行带「查看驳回原因」链接。
- 右上信息卡：会员昵称与头像、等级胶囊「Lv3 中级会员」与「再获 35 积分升级」（激励琥珀色系）、积分余额「465 积分」。
- 空列表提示示例：「还没有发表过内容，去浏览板块」。
- 状态一律「色块＋文字」双表达；不出现任何支付、红包、现金、会员卡类元素。

三、风格锚定（必须严格遵守，引自项目层脚本）
- 主色（品牌蓝）#2A6CBE：顶部导航与主按钮、链接、选中态；按下态 #1F5497；浅底选中 #E8F1FB。
- 副色（激励琥珀）#C97A16：悬赏、积分、等级标识专用；浅底 #FAF1E3。
- 语义色：成功 #15803D（已通过、已采纳、已结算）、警示 #B45309（待审核、待处理）、危险 #B91C1C（驳回、删除、封号）、信息 #2A6CBE。
- 中性色：页面底 #F5F7FA、卡片 #FFFFFF、分割线 #E5E8EB、次级文字 #5B6570、正文 #1F2328、禁用 #9AA4AF。
- 字体：中文系统字体栈（苹方／思源黑体／微软雅黑），正文 14px、标题 16px～20px，行高 1.6。
- 形态：卡片圆角 8px、按钮与输入框圆角 6px、列表行高 44px、头像圆形、标签与状态用胶囊；状态一律「色块＋文字」双表达，不靠颜色单独承载语义。
- 通用禁止：不出现英文界面文字；不出现应用商店、手机 App 图标、小程序外壳；不出现真人照片、第三方品牌标识与真实机构名；不使用大面积渐变、霓虹色、玻璃拟态与 3D 元素；不使用夸张阴影；不出现倒计时、抢购、优惠券等电商化元素；不使用未成年人形象。

四、本版附加禁止
- 不出现积分人工修正入口（随 0.7）；不出现内容迁移或导出入口；不出现关注流或推荐流界面；不出现收藏问题或收藏答案的按钮；不出现话题与问答发表界面的任何改动（沿用既有界面）。

五、提示词结构要求
按「画面类型与画布尺寸 → 页面结构分区描述 → 每个分区的元素与文案示例 → 色彩与字体与形态 → 光影与质感 → 负向要求」的顺序组织；文案示例用简体中文并逐字取自《术语表（项目）》与本话术。

六、输出
只输出这段生图提示词，并在末尾用三行说明：你为谁设计、为什么核心界面是个人中心首页、这张图承担什么作用。
```

## 2. 第二步：生成并迭代核心界面

```text
按你刚才输出的提示词生成图片。生成后请逐项自检并告诉我：必须元素是否齐全（聚合导航七项、我的内容四类分组与三种状态标识、驳回原因入口、等级与积分信息卡、注销入口）、色值是否贴近主色 #2A6CBE 与激励琥珀 #C97A16、是否有英文文字或禁止元素。
```

迭代方法：对不满意处逐条提出（如「把注销入口移到导航最底部并加分割线」「把等级胶囊与积分余额合并为一行」），每轮只改一到两处；满意后即本版基准，并与项目层脚本生成的主页基准并检一次——核对配色、圆角、密度与信息层级同源，防跨版本风格漂移。

## 3. 第三步话术：规划本版其余图片并逐张撰写提示词

```text
核心界面已定稿，作为本版风格基准。请先只输出一份图片清单（不要生成图片），说明每张图的名称、所属端、作用，以及你建议的总数。

覆盖要求（必须满足）：
- 端：前台界面为电脑端网页（1440×900）为主、手机端网页（390×844，网页形态而非 App 外壳）至少覆盖个人中心首页与我的积分两张；管理后台（1440×900）含等级权益配置与流水查询两张。
- 前台必含界面（核心界面已生成，其余按此清单补齐，可合并或拆分并说明理由）：
  1) 我的收藏：已收藏话题列表（标题、作者、收藏时间，倒序分页）；空态一「还没有收藏内容」。
  2) 我的点赞：点过赞的内容列表（话题／评论／问题／答案四类类型标识）；空态二「还没有点赞过内容」。
  3) 我的积分与等级：余额、当前档位「Lv3 中级会员」「再获 35 积分升级」、流水列表（来源类型、方向、数值、时间）；空态三（新会员无流水时的引导）。
  4) 我的资料与凭据：昵称与头像维护、修改密码表单；异常态一——原密码错误提示「原密码不正确」。
  5) 注销流程集：申请入口→异常态二（存在待结算悬赏时阻断，危险色提示「请先处理待结算悬赏」）→二次确认弹层（「注销后不可恢复，已公开内容将保留并显示为已注销会员」）→注销完成通知→异常态三（注销后再登录被拒提示）。
  6) 已注销会员占位态：前台内容页作者显示「已注销会员」占位（默认头像、无等级胶囊）。
- 管理后台必含界面：
  7) 等级权益配置页：五档（Lv1 新手上路～Lv5 资深会员）开放范围与权限集合配置表、保存按钮；异常态四——配置不完整保存拦截提示；默认值一键回填。
  8) 流水查询（经营侧）：按会员（昵称／编号）与时间区间筛选的流水列表（只读）；空态四——无匹配结果。
- 无界面声明（不生成图）：我的私信与通知提醒——沿用 0.4 消息中心既有界面，个人中心仅入口聚合不重画；等级展示——随既有页面渲染的档位胶囊与积分差（无独立界面，已并入个人中心首页与我的积分页）；话题、问答、板块等界面沿用既有不重画。
- 关键信息点：状态标识（已公开／待审核／已驳回）、档位名称、积分差、注销阻断与确认文案，均按上述文字逐字呈现；界面用词逐字取自《术语表（项目）》与本清单。
- 本版范围外界面不得出现（同第一步附加禁止）。

清单确认后，请逐张输出生图提示词（每次一张，结构同核心界面），我确认后再生成。
```

## 4. 第四步：批量生成

```text
按清单顺序逐张生成，每张生成后按同一标准自检：与本版核心界面基准一致（配色、圆角、密度、信息层级）、界面文字全中文且与术语表一致、无禁止元素。有偏差时先修正再进入下一张。
```

单张迭代方法：只描述要改的地方与期望效果，一次一到两处，避免整张重写导致风格漂移。

## 附注 其他生图模型的差异

无对话记忆的模型（如即梦等单次生图工具）无法「先出提示词、再规划清单」：使用时把第 1 步与实际界面要点一次性写进单张提示词，先只出核心界面并定稿，再把核心界面图作为风格参考图连同第 3 步的覆盖要求逐张生图；附 A 与附 B 的用法不变。
