## 3. 运行方式

本版为文档范本演练，无真实代码产物；按技术文档（项目）口径的运行形态如下（模拟叙述）：

1. 环境：单体应用（Java＋Spring Boot，内含前台与管理后台 Vue 静态资源）单实例部署，MySQL 数据库。
2. 升级顺序：先执行数据库升级（member_account 增列 cancelled_at；site_setting 写入 level_benefit_lv1～lv5 五键初始值）→ 部署应用（前台新增个人中心聚合面；管理后台新增等级权益配置页与流水查询页）→ 按 PRD 完成标志全链路演练验收（注销演练置于最后）。
3. 依赖说明：等级判定与流水读取调用 v0.3.0 成长模块；资料凭据校验沿用 0.1 会员与权限模块；消息能力沿用 0.4 消息模块（入口聚合不改能力）。
