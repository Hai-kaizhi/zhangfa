> 定位：本版（问答与悬赏闭环）开发交付说明——承接《PRD（小版本）v0.3.1》认领条目 R61～R76 的实现与验收自检；本版为文档范本演练，无真实代码产物，运行与证据均为文档范本演练的模拟口径；上游为模拟案例材料，模拟性质予以保留。

| R73 悬赏到期退回 ◆ | 单体应用·问答与悬赏模块（到期退回定时任务） | 任务可重入：已结算／已撤回跳过、未到期保留；到期项（到期时点＝提问公开＋14 天）同一事务冲正退回（反向流水，来源类型＝悬赏退回）、悬赏置已撤回、问题置已关闭、通知提问人（通知类型＝悬赏退回）；同一悬赏不重复退回 |

| R76 问答搜索 | 前台·站内搜索扩展（沿用 0.2 搜索入口与机制） | 检索范围扩展至已公开的问题与答案；结果按问题／答案两类呈现，答案结果进入所属问题详情；待审核与已驳回零泄漏；无结果空态 |

范围核对：仅实现 R61～R76；范围外声明（PRD §1）零越界——治理侧删除与举报、个人中心展示、积分人工修正、问答收藏均未出现在本版交付中；版主审核沿用 0.2 待审队列无新增操作面。

## 3. 运行方式

本版为文档范本演练，无真实代码产物；按技术文档（项目）口径的运行形态如下（模拟叙述）：

1. 环境：单体应用（Java＋Spring Boot，内含前台与管理后台 Vue 静态资源）单实例部署，MySQL 数据库。
2. 升级顺序：先执行数据库升级（新建 question、answer、bounty 三表，字段按 PRD §5 与术语表 §7；审核队列 content_type 取值扩展启用）→ 部署应用（前台新增问答标签页、提问页与问题详情；通知与点赞取值扩展启用）→ 部署悬赏到期退回定时任务（演练以手动触发表达）→ 按 PRD 口径一／口径二路径演练验收。
3. 依赖说明：积分出入账、冲正与等级判定调用 v0.3.0 已交付的成长模块接口；审核、敏感词、通知沿用 0.2 队列与写入机制。
