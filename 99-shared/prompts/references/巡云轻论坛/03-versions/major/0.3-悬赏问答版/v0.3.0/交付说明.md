## 3. 运行方式

本版为文档范本演练，无真实代码产物；按技术文档（项目）口径的运行形态如下（模拟叙述）：

1. 环境：单体应用（Java＋Spring Boot，内含管理后台 Vue 静态资源）单实例部署，MySQL 数据库。
2. 升级顺序：先执行数据库升级（新增 site_setting 本版 9 键并写入本版定案初始值；point_account、point_transaction 建表，字段按 PRD §5 与术语表 §7）→ 跑存量会员补开任务（幂等可重跑）→ 部署应用 → 管理后台全站设置页出现「等级与积分规则配置」入口（仅站长角色可见）。
3. 演练验收：按第 2 节验收锚逐条演练（注册开账、入账、预扣冲正、判级变更、配置与拦截），证据口径为界面叙述／接口叙述／日志行。
