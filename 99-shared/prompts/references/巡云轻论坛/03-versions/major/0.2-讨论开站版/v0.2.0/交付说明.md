| R40 审核驳回 ◆ | 同上 | 原因 2～200 必填；同事务回写已驳回＋记录＋通知；原因对作者可见、他人不可见 |
| R41 词条新增与编辑 | 单体应用·审核与治理模块（词表服务）；管理后台·敏感词页 | 词条 2～30 唯一＋启停；保存留痕并即时生效于后续提交 |
| R42 词条删除 | 同上 | 删除留痕；历史命中标记不受影响 |

| R44 写入通知提醒 ◆ | 单体应用·消息模块（统一写入接口） | 审核通过／审核驳回／评论公开三类事件同事务写入；文案系统统一生成；接收人不可达静默丢弃；失败整体回滚 |
| R45 查看通知提醒 | 单体应用·消息模块（查询服务）；前台·通知入口 | 本人通知按时间倒序分页 20；点击跳关联内容；已删除内容跳转显示不可见文案；已读标记随 0.4 |

数据落库：topic、comment、topic_tag、audit_record、sensitive_word、notification 六表按 PRD 第 5 章与术语表命名建表；沿用 v0.1 各表只读引用。同事务契约：提交（话题／评论写入＋队列项＋命中标记）、审核结论（回写＋记录＋通知）、删除（状态＋互动关系位＋计数回减）均实现为同一本地事务。

## 3. 运行方式

- 服务端：单体应用（Spring Boot）沿用 v0.1 部署形态，配置 application.yml 后以 Maven 启动；本版新增六张表的初始化迁移脚本随应用执行。
- 前台：电脑端网页与手机端网页同一站点响应式输出，板块导航、话题、评论、搜索与通知入口为新增前台路由。
- 管理后台：独立前端工程新增「待审队列」与「敏感词」两页，按能力点渲染（版主与站长角色由 v0.1.0 角色定义追加勾选）。
- 域名与备案：对外访问依赖域名注册与备案收口（路线图 0.1 启动、本版收口，发布环节执行）。
