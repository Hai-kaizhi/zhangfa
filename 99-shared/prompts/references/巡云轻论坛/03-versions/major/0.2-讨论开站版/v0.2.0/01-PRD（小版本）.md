# PRD（小版本）：v0.2.0 讨论闭环

> 定位：开发级需求说明书——承接大版本 PRD 0.2 与其 02 批次一，认领自需求池（R24～R45，状态已迁移为已认领（v0.2.0））；用途与验收标准逐字锚定上游、只细化不改写；上游为模拟案例材料，模拟性质予以保留。

## 1. 版本概述

**承接与目标**：认领来源＝0.2 讨论开站版批次一「讨论闭环」（简单场景采纳整批，R24～R45）＋需求池实时状态合并（池内该 22 条均为待规划，无池直入条目混入）。本版可验收形态＝02 批次一可验收形态——可演示路线图完成标志路径：一名访客完成「注册 → 浏览板块 → 发表话题 → 审核通过公开 → 被其他会员评论」，全程通知送达、待审核与已驳回内容零泄漏。量化口径沿用大版本 PRD（开站路径 100%、先审后发零泄漏；经营验证数值口径立项时定值）。

**范围外声明**：R46～R53（点赞与收藏、会员账号状态处置）随批次二（下一小版本）认领；问答与悬赏、积分与等级随 0.3（可见规则的等级与积分判定为先行设置、0.3 接入生效）；标记已读与清理随 0.4；举报与治理侧删除、会员与内容查询维护随 0.6；运营内容与浏览量统计随 0.6／0.7。板块与标签的维护界面已随 v0.1.1 交付，本版仅消费其数据。

**条目内顺序与依赖**（引用上游批内说明）：前台结构入口（R24～R26）与话题生命周期（R27～R31）先行；审核（R38～R40）、敏感词（R41～R43）、通知（R44～R45）同批联调——内容提交与审核记录同事务、审核结论与状态回写／留痕／通知同事务为不可回退契约；评论（R35～R37）依赖话题公开；浏览检索（R32～R34）贯穿收口。

## 3. 核心用户旅程

**旅程承接说明**：承接大版本 PRD 0.2 的四条旅程——旅程一（发表话题并经审核公开）、旅程三（驳回后修改重提）、旅程四（访客浏览与搜索）全程在认领范围内；旅程二（评论与互动）的评论与通知段在本版，点赞与收藏段显式不在本版旅程内（随 v0.2.1）；四条旅程的取值与反馈均用本版已落地口径。

### 3.1 旅程一：发表话题并经审核公开（会员与版主·跨主体）

会员登录后从首页进入板块（启用状态板块可见），选用标签（1～5 个）填写标题（2～100 字符）与正文、可设可见条件后提交；系统同事务写入话题（待审核）与审核队列项，敏感词命中的条目被标记优先；版主在待审队列执行通过（内容立即公开进入列表与搜索、通知作者）或驳回（填写 2～200 字符原因，作者收到含原因通知）。

```mermaid
sequenceDiagram
    participant 会员
    participant 前台站点
    participant 版主
    Note over 会员,版主: 提交与队列项同事务；结论与回写留痕通知同事务
    会员->>前台站点: 选板块发话题（标签 1～5 个、标题、正文、可见条件）
    前台站点->>前台站点: 敏感词命中校验（命中标记优先）
    前台站点->>版主: 待审队列出现该话题
    版主->>前台站点: 通过
    前台站点-->>会员: 话题公开＋通知：审核通过
    版主->>前台站点: 或驳回（原因 2～200 字符）
    前台站点-->>会员: 已驳回＋通知：审核驳回与原因
```

操作步骤清单：1. 会员登录并进入板块；2. 点击发帖，填标签、标题、正文并选择可见条件；3. 提交后在我的内容处显示待审核；4. 版主在待审队列处理；5. 通过后话题公开、驳回则按通知修改重提。

### 3.2 旅程二（评论段）：在公开话题下评论并通知作者

其他会员进入已公开话题详情，提交评论（2～1000 字符）或对评论回复；评论进入待审，版主通过后公开展示并通知话题作者，驳回则评论人收到含原因通知——点赞与收藏互动段不在本版旅程内（随 v0.2.1）。

```mermaid
sequenceDiagram
    participant 其他会员
    participant 前台站点
    participant 版主
    participant 话题作者
    其他会员->>前台站点: 查看公开话题详情
    其他会员->>前台站点: 提交评论或回复（2～1000 字符）
    前台站点->>版主: 评论进入待审队列
    版主->>前台站点: 通过
    前台站点-->>话题作者: 通知：你的话题有新评论
    前台站点-->>其他会员: 评论公开展示
```

操作步骤清单：1. 进入公开话题详情并阅读评论；2. 填写评论或回复提交；3. 版主审核；4. 通过后评论公开且作者收到通知。

### 3.3 旅程三：驳回后修改重提（会员·单端）

作者在我的内容入口看到已驳回状态与驳回原因，修改标题、正文或可见条件后重新提交，话题回到待审核并生成新的审核记录；循环直至通过或删除放弃。

```mermaid
flowchart TD
    A[会员：我的内容查看已驳回与原因] --> B[修改标题 正文或可见条件]
    B --> C[重新提交 回到待审核 新审核记录]
    C --> D{版主结论}
    D -->|通过| E[话题公开]
    D -->|再次驳回| A
    A --> F[或删除放弃 终态]
```

操作步骤清单：1. 定位已驳回话题；2. 查看驳回原因；3. 修改后重新提交；4. 等待新结论；5. 需要时删除放弃。

### 3.4 旅程四：访客浏览与搜索（访客·单端）

访客打开首页看到启用板块（名称与说明），进入板块内容列表（已公开话题按发布时间倒序，含标题、作者、评论数、点赞数与标签），点击进入详情阅读正文与评论，或关键词搜索（只返回已公开且可见的话题）；参与时被引导注册。

```mermaid
flowchart TD
    A[访客：打开首页] --> B[启用板块列表 名称与说明]
    B --> C[板块内容列表 已公开话题倒序]
    C --> D[话题详情 正文 标签 已公开评论]
    B --> E[或按标签查看同类话题]
    A --> F[或关键词搜索]
    F --> G[结果只含已公开且可见]
    D --> H[尝试发帖或评论]
    H --> I[引导注册登录]
```

操作步骤清单：1. 打开首页浏览板块；2. 进入板块或标签列表；3. 阅读详情与评论；4. 或关键词搜索；5. 参与时注册。

### 4.1 R24 板块列表与导航

**功能说明**：前台按板块组织内容的一级入口。触发：访客或会员打开站点首页，或点击顶部板块导航。

**交互与流程**：

```mermaid
flowchart TD
    A[访客或会员：打开首页] --> B[系统读取启用状态板块]
    B --> C{是否存在启用板块}
    C -->|无| D[空态：暂无板块 请稍后再来]
    C -->|有| E[展示板块名称与说明]
    E --> F[点击板块进入内容列表]
```

操作步骤清单：1. 打开首页；2. 查看启用板块；3. 点击进入目标板块。

**字段与校验**：

| 字段 | 必填 | 业务类型 | 落库字段名 | 约束与取值 |
|---|---|---|---|---|
| 板块名 | —（展示） | 文本 | board_name | 取自板块表（v0.1.1） |
| 说明 | —（展示） | 文本 | description | 同上 |
| 状态 | —（过滤） | 状态 | status | 仅展示启用（术语表） |

**规则与边界**：(1) 首页只展示启用状态板块，停用板块不出现在前台（验收锚）；(2) 板块排序按 sort_order（同值按创建时间，沿用 v0.1.1）；(3) 本条为只读消费，板块数据由 v0.1.1 管理界面维护。

**异常与拦截**：无启用板块→首页显示空态「暂无板块，请稍后再来」；板块在访问瞬间被停用→列表不展示该板块（下次读取生效）。

**交互与流程**：

**规则与边界**：(1) 只展示已公开评论，待审核与已驳回不展示（验收锚）；(2) 按时间正序、分页 20 条／页（本版采用）；(3) 评论数（comment_count）随公开评论计数。

**异常与拦截**：无评论→空态；父级已删除→占位「该评论已删除」。

## 6. 待议与建议

**本版采用的推断与默认值汇总**（均已就地标明）：标题 2～100 字符、正文 ≤50000 字符、标签 1～5 个、评论 2～1000 字符、两级评论层级、驳回原因 2～200 字符、词条 2～30 字符、关键词 1～50 字符、各列表分页 20 条／页、命中匹配为不区分大小写的全量精确匹配、词表读取失败按未命中入队、重提次数不设上限、空标签不出现在聚合位、等级与积分条件本版视同公开——以上均为行业惯例默认或本版拍板，可随评审调整。
