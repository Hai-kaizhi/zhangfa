# 交付说明：v0.2.1

> 定位：本版开发交付说明——承接《PRD（小版本）v0.2.1》认领条目 R46～R53 的实现清单、验收锚自检、运行方式与已知限制；本交付为**文档范本演练**（不产出代码文件），实现位置为按技术文档模块划分的约定落位、验收证据为模拟演练证据；上游为模拟案例材料，模拟性质予以保留。

## 1. 实现清单（条目｜代码位置｜实现要点）

| 条目 | 代码位置 | 实现要点 |
|---|---|---|
| R46 点赞 | 单体应用·互动模块（点赞服务）；前台·话题详情互动位 | 仅已公开内容可赞；member_id＋content_type＋content_id 联合唯一约束幂等；关系与计数同事务 |
| R47 取消点赞 | 单体应用·互动模块；前台·互动位 | 移除关系计数即时减一；未点赞取消幂等；内容已删除时幂等成功 |
| R48 点赞计数 | 单体应用·互动模块（计数服务）；前台·详情与列表渲染 | 话题与评论 like_count 展示；与关系记录一致；冗余值可重算校正；v0.2.0 先行展示位自此有真实取值 |
| R49 收藏 | 单体应用·互动模块（收藏服务）；前台·话题收藏位 | 仅已公开话题可收藏；联合唯一幂等提示已收藏；收藏列表界面随 0.5，本版仅操作位反馈 |
| R50 取消收藏 | 单体应用·互动模块；前台·收藏位 | 移除关系恢复可收藏；未收藏取消幂等 |
| R51 禁言 | 单体应用·会员与权限模块（处置服务）＋审核与治理模块（入口）；管理后台·违规处置面板 | 期限四选一（1／3／7／30 天默认 7 天）落 mute_until；状态置禁言＋留痕（operation_log）＋通知（notify_type=禁言）同事务；发言校验对接 v0.2.0 先行拦截；处置入口＝待审队列条目与内容作者处 |
| R52 解除禁言 | 同上 | 人工解除立即恢复（留痕＋通知）；期满定时任务自动解除（留痕、不发通知、可重入） |
| R53 封号 | 同上 | 二次确认输入「封号」二字；状态终态＋销毁登录态＋留痕＋通知同事务；公开内容按保留策略保留 |

数据落库：like_record、favorite 两表新建（联合唯一约束）；member_account 新增 mute_until 字段与三态生效（正常／禁言／封号）；notification 新增 notify_type 取值（禁言／解除禁言／封号）。同事务契约：点赞／收藏关系与计数同事务；禁言／解除／封号的状态变更、留痕、通知同事务。

自检结论：8／8 通过（证据为模拟演练口径）。

## 3. 运行方式

- 服务端：单体应用（Spring Boot）沿用既有部署形态；本版新增两张表与 mute_until 字段的迁移脚本随应用执行；期满自动解除为应用内定时任务（可重入）。
- 前台：话题详情与列表的点赞、收藏操作位随本版启用（v0.2.0 先行展示位接入真实计数）。
- 管理后台：独立前端工程新增「违规处置面板」入口（待审队列条目与已公开内容作者处），按版主能力点渲染。
