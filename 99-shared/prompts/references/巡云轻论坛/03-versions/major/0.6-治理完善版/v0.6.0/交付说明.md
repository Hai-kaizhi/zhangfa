## 3. 运行方式

本版为文档范本演练，无真实代码产物；按技术文档（项目）口径的运行形态如下（模拟叙述）：

1. 环境：单体应用（Java＋Spring Boot，内含前台与管理后台 Vue 静态资源）单实例部署，MySQL 数据库。
2. 升级顺序：先执行数据库升级（新建 report、operation_content 两表，字段按 PRD §5 与术语表 §7）→ 部署应用（前台内容操作区新增举报按钮、个人中心新增我的举报、前台运营位渲染；管理后台新增举报处置、留痕查询、运营内容维护、会员与两张内容检索页）→ 按 PRD 完成标志全链路演练验收（举报→核实处置→删除→通知→留痕回溯＋检索维护＋运营内容）。
3. 依赖说明：处置动作消费 0.2 禁言与封号、内容状态回写经各内容模块、互动清理联动互动模块、通知经 0.2 统一写入机制（新类型已登记）。
