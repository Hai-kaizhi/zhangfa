# 领课教育

> 单机构自建自营的在线教育系统（模拟案例）：学员端门户、讲师端工作台、机构端 PC 管理后台三个端；以点播课程为核心交付形态。本项目是提示词驱动文档体系的示范项目，由现行提示词体系从零重建，模拟性质全篇保留。
