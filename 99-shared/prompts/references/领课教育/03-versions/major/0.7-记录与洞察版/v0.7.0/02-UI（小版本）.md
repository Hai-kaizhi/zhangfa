## 1. 第一步话术：让 GPT 产出本版核心界面的生图提示词

> 复制下面整段发给 GPT（资料已在上文给过）：

```
你是资深 UI/UX 设计师，精通中文界面设计与生图提示词撰写。

我在做一个在线教育系统（三端网页：学员端、讲师端、机构端管理后台）的经营洞察版本。请先通读我给你的资料（小版本 PRD、项目层 UI 脚本、术语表），只做理解，不要生成任何图片。

任务：为这个产品的【机构端「订单统计页」】撰写第一张图的生图提示词。

一、这张图必须包含的元素（机构端·订单统计页）：
- 顶部：机构端管理后台框架（站点名称、主导航含「订单统计」，当前处于订单统计）
- 筛选区：时间范围选择器（默认「近 30 天」，快捷项「近 7 天／近 30 天／自定义」，自定义起止日期）
- 总量卡区：两张指标卡——「成交金额」大号数字（如 12,450.00 元）与「订单量」（如 50 单），注明统计区间
- 趋势区：按日汇总双折线图（成交金额折线＋订单量折线，数据可视化用点缀色与主色，坐标轴含日期）
- 课程维度汇总表：课程名称、成交金额、订单量三列，按成交金额倒序（3～4 行示例数据）
- 页面不出现学员的个人资料与联系方式（只呈现聚合结果）

二、全局风格锚定（必须严格遵守，不得自行改色）：
- 产品气质：可信、清晰、有学习氛围的在线教育平台；界面克制、信息层级清楚，不花哨
- 主色（品牌色）：#0056D2（用于主按钮、选中态、链接与关键强调）
- 副色／点缀色：#03C7E8（仅用于进度条、数据可视化与轻量强调，不用于大面积背景——趋势折线可用）
- 中性色：页面底 #F5F6F8；卡片与内容底 #FFFFFF；标题文字 #1C1D1F；正文 #454545；辅助文字 #707070；分隔线与描边 #E1DDDB
- 语义色：成功 #0D7D4D；警告 #D6B600；危险 #AB0D02；信息 #00688D
- 色板配比：中性色承担 80% 以上面积，主色用于操作与强调，点缀色占比不超过 5%
- 字体：中文无衬线（PingFang SC／Microsoft YaHei／Noto Sans CJK SC），数字与拉丁用 Inter；标题与正文层次靠字重与字号，不靠颜色堆叠；金额数字用等宽数字
- 组件形态：卡片圆角 8px、按钮圆角 6px、输入框圆角 6px；描边 1px；阴影克制（仅用于浮层），不用大面积渐变色与发光效果
- 无障碍：正文文字与背景对比度不低于 4.5:1；不使用在白底上对比不足的浅色文字

三、通用禁止（任何一张图都不允许出现）：
- 全中文界面（不得出现英文界面文案与英文占位词）；只允许极少量数字与金额
- 不出现第三方品牌标识、平台水印、二维码、联系方式
- 不出现真实人物照片、真实机构名与真实版权课程名（本项目为模拟案例，课程与讲师名为虚构）
- 不出现直播、在线考试与题库、任务打卡与积分证书、社区问答与博文等本期不做功能的入口
- 不出现手机 App 与小程序界面形态（本产品三端均为网页形态）
- 不出现学员端与讲师端的界面元素混入机构端
- 不使用深色模式与高饱和撞色，不使用拟物与 3D 装饰元素

四、本版附加禁止（v0.7.0 范围外，同样不得出现）：
- 不出现导出、下载报表按钮（导出本版不排期）
- 不出现结算、对账、提现等资金流转元素（收益只做呈现）
- 不出现经营预测、多机构对比、行业对标元素
- 不出现学员姓名、手机号等个人资料（统计只呈现聚合结果）

五、输出要求：
1. 先只输出**生图提示词本身**，不要生成图片。
2. 提示词用中文撰写，结构为：画面类型与宽高比 → 页面结构与区块顺序 → 各区块的界面元素与文案 → 整体风格锚定（色值、字体、组件形态）→ 禁止项。
3. 宽高比：桌面端 16:10（1440×900 视口）。
4. 界面文字直接写进提示词（生图模型的文字渲染不可靠，我会在生图后逐处校正）。
5. 先只给我这一张（订单统计页）的提示词，等我确认后再生图；不要提前规划其他页面。
```

## 2. 第二步：生成并迭代核心界面

> 拿到提示词后复制下面这句：

```
请按上面的提示词生成图片。生成后请对照提示词自检：区块是否齐全、色值是否按锚定执行、界面文字是否可读且无英文、是否有被禁止的元素（尤其注意：不得出现导出按钮／结算元素／学员个人资料）。列出偏差，并给出修正后的提示词。
```

迭代方法：

1. 每次只改一处（区块、色值、文案），避免一次改多项后分不清哪次变动生效。
2. 满意的订单统计页即为**本版风格基准**：本版其余图片都以它为准，不重新定义色板与组件形态。
3. 与项目层主页基准及既有机构端界面基准**并检一次**：并排比对字体层次、卡片圆角与色板是否同源，防止跨版本风格漂移；发现漂移以项目层附 A 色值为准修正提示词。
4. 生图必然色偏：图片像素取色仅作参考，**色值以本脚本附 A（引自项目层）为唯一来源**（代码层按附 A 实现）。
5. 出现本版附加禁止所列元素（导出、结算、预测等）时，直接判为不合格并要求重出，不手动修补。

## 3. 第三步话术：规划本版其余图片并逐张撰写提示词

> 核心界面定稿后复制下面整段：

```
订单统计页已定稿，它现在是本版本的风格基准：色板、字体层次、组件形态一律以它为准，不得改变。

请规划本版本（v0.7.0 记录与洞察）其余需要出图的界面，并按覆盖要求逐张撰写生图提示词。

一、覆盖要求（必须全部覆盖，一张图或一组图覆盖一项；认领条目为 R52 我的订单查看、R53 学习记录查看、R54 订单统计查看、R55 课程收益查看）：
1. 学员端（桌面 16:10）：个人中心页（入口聚合：我的订单、学习记录、资料与密码——0.1 交付项随入口呈现）；「我的订单」列表页（订单编号、课程名称、金额、状态标签〔待支付／已支付／已取消〕、下单时间、支付时间，待支付行「继续支付」入口，分页 10／20／50）；订单详情页（订单信息＋支付留痕流水表：外部单据号、金额、结果、支付时间）；我的订单空态（「还没有订单，去逛逛」）；「学习记录」列表页（课程名、已学课时数／总数如 2／4、进度百分比与进度条、最近学习时间精确到分钟，未开始标注）；学习记录空态（「还没有课程，去逛逛」）
2. 机构端（桌面 16:10）：订单统计空态（「该时间范围内暂无成交」）；时间跨度超限提示（「时间范围最长 1 年」）；「课程收益」页（机构管理员视角：按课程分组——课程名称、收益金额、成交订单量，时间范围口径同订单统计，收益金额倒序）；无统计查看权限提示（「无统计查看权限」／「无收益查看权限」）
3. 讲师端（桌面 16:10）：「课程收益」页（讲师视角：仅本人课程分组，导航新增「课程收益」入口）；收益空态（「该时间范围内暂无收益」）；越权提示（「无权查看该课程收益」——可并入异常态组图）
4. 机制条目声明：本版无机制条目——四条认领条目均有操作面；派生视图（订单统计／课程收益）为查询口径组合、无独立机制界面
5. 手机形态：本版不新增手机界面（记录与统计以 PC 为主用形态；手机适配建议随回池项评估）

二、各界面的关键信息点（必须画出来）：
- 学员订单状态标签三色：待支付（信息色）、已支付（成功色）、已取消（辅助色）；未支付订单支付时间显示「——」
- 订单详情支付留痕与机构端同口径（外部单据号、金额、结果〔成功／失败／金额异常〕、支付时间，金额异常行标红）
- 学习记录进度条用点缀色；「未开始」标注用辅助文字色
- 收益页与订单统计页时间范围控件同构（近 7 天／近 30 天／自定义）
- 三端导航：学员端「首页／课程／我的课程／个人中心」；机构端含「订单统计」「课程收益」；讲师端含「课程收益」
- 统计与收益页不出现任何学员个人资料

三、宽高比：全部为桌面端 16:10（1440×900）。三端均为 PC 网页形态。

四、输出顺序要求：
1. 先给出**图片清单**：每张图一行（图名／所属端／作用／宽高比），并说明总数与顺序理由，等我确认。
2. 确认后再**逐张输出生图提示词**（一次一张，结构同第一张：画面类型与宽高比 → 页面结构 → 元素与文案 → 风格锚定 → 禁止项），不要一次输出全部。
3. 全部遵循第一张的风格锚定与通用禁止＋本版附加禁止；不得引入新的色值。
```

## 4. 第四步：批量生成

> 清单确认后，逐张复制：

```
按这张的提示词生成图片。生成后自检并列出偏差：区块是否齐全、色值是否与风格锚定一致、文字是否全中文、是否出现被禁止的元素（含本版附加禁止：导出／结算／预测／学员个人资料不得出现）；有偏差时给出修正后的提示词。
```

单张迭代方法：只改一句话（改区块／改色／改文案），每次生成后与本版第一张（订单统计页）并排比对风格一致性；连续两次仍偏离时，回到提示词层面重写该区块描述，而不是继续叠加修正语。

## 5. 收尾：回填归档

1. 把每张图的最终结果与偏差填写到**附 B 生图回填区**。
2. 若生图过程中对色值做了微调（只允许微调明度），**同步更新项目层脚本附 A**（唯一来源）与本脚本附 A，确保代码层与设计同源；本脚本不自定新色值。
3. 界面文案以本版 PRD 与术语表的用词为准（学员、机构管理员、机构运营人员、讲师、订单编号、我的订单、学习记录、订单统计、课程收益等称谓逐字沿用）：生图模型的界面文字不可靠，出图后逐处校正；本版不出现的业务概念（导出、结算、预测、学员个人资料）如混入图中，判为不合格重出。
4. 本版新增界面的要素不回写项目层脚本（风格变更才回写项目层）。

## 附注 其他生图模型的差异

对无对话记忆的模型（如即梦等）：把本脚本第 1 步话术中的「风格锚定」「通用禁止」「本版附加禁止」三段原文，连同 GPT 已写好的单张生图提示词，拼成一段一次性提交；每张图都重复带上风格锚定，避免模型自行改色。第 3 步的「让 GPT 规划清单」改为人工按覆盖要求逐项对照，仍遵守「数量与顺序由规划结果说明、不写死」的原则。
