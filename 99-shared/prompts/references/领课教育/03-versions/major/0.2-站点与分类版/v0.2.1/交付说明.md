## 3. 运行方式

- 后端：站点配置模块（对接参数部分）随单后端应用启动（连 MySQL 与 Redis）；媒体接入模块加载部署配置的两家服务商适配器（视频点播／对象存储）。
- 前端：机构端工程本地 `dev` 启动或 `build` 部署（站点配置页·对接参数区，管理员形态）。
- 验证路径：管理员查看两组接入项（脱敏与空态）→配置存储服务（校验通过保存留痕）→以错误凭据／不可达地址／挂起地址各试一次（保留原参数与三类提示）→运营人员访问被拒（即 PRD 旅程一遍）。
