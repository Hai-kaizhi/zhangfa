## 3. 运行方式

- 后端：站点配置模块与课程模块（分类部分）随单后端应用启动（连 MySQL 与 Redis）；执行迁移脚本建 `site_config`（唯一一份，含占位初始化行）与 `course_category`（`parent_id`＋`name` 同级唯一索引）。
- 前端：机构端工程本地 `dev` 启动或 `build` 部署（站点配置、分类管理路由）。
- 验证路径：管理员查看并修改站点信息（含保留字拦截）→ 运营人员搭分类树（增改删）→ 机构端全量核对 → 学员端可用分类接口核对（即 PRD 两条旅程一遍）。
