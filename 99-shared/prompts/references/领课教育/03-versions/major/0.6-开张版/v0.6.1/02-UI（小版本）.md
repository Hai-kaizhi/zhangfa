## 1. 第一步话术：让 GPT 产出本版核心界面的生图提示词

> 复制下面整段发给 GPT（资料已在上文给过）：

```
你是资深 UI/UX 设计师，精通中文界面设计与生图提示词撰写。

我在做一个在线教育系统（三端网页：学员端、讲师端、机构端管理后台）的在线学习版本。请先通读我给你的资料（小版本 PRD、项目层 UI 脚本、术语表），只做理解，不要生成任何图片。

任务：为这个产品的【学员端「课程学习页」】撰写第一张图的生图提示词。

一、这张图必须包含的元素（学员端·课程学习页）：
- 顶部：学员端门户框架（站点名称、主导航「首页／课程／我的课程」，当前处于某课程学习中）
- 播放区（页面主体上部）：视频播放器（正在播放画面占位，可含播放控制条：进度、音量、全屏——为播放器控件而非业务功能）与当前课时标题「第 2 课 开发环境准备」
- 课时目录区（侧边或下部）：标题「课程目录」＋课时清单按学习顺序（序号＋课时标题＋已学标记——已学课时带成功色对勾、当前课时高亮、未学课时常态），目录顶部「继续学习：第 2 课」入口
- 按 4 个课时（2 已学＋1 当前＋1 未学）的状态画；不出现「我的订单」「学习记录」等入口

二、全局风格锚定（必须严格遵守，不得自行改色）：
- 产品气质：可信、清晰、有学习氛围的在线教育平台；界面克制、信息层级清楚，不花哨
- 主色（品牌色）：#0056D2（用于主按钮、选中态、链接与关键强调）
- 副色／点缀色：#03C7E8（仅用于进度条、数据可视化与轻量强调，不用于大面积背景）
- 中性色：页面底 #F5F6F8；卡片与内容底 #FFFFFF；标题文字 #1C1D1F；正文 #454545；辅助文字 #707070；分隔线与描边 #E1DDDB
- 语义色：成功 #0D7D4D；警告 #D6B600；危险 #AB0D02；信息 #00688D
- 色板配比：中性色承担 80% 以上面积，主色用于操作与强调，点缀色占比不超过 5%
- 字体：中文无衬线（PingFang SC／Microsoft YaHei／Noto Sans CJK SC），数字与拉丁用 Inter；标题与正文层次靠字重与字号，不靠颜色堆叠
- 组件形态：卡片圆角 8px、按钮圆角 6px、输入框圆角 6px；描边 1px；阴影克制（仅用于浮层），不用大面积渐变色与发光效果
- 无障碍：正文文字与背景对比度不低于 4.5:1；不使用在白底上对比不足的浅色文字

三、通用禁止（任何一张图都不允许出现）：
- 全中文界面（不得出现英文界面文案与英文占位词）；只允许极少量数字与金额
- 不出现第三方品牌标识、平台水印、二维码、联系方式
- 不出现真实人物照片、真实机构名与真实版权课程名（本项目为模拟案例，课程与讲师名为虚构）
- 不出现直播、在线考试与题库、任务打卡与积分证书、社区问答与博文等本期不做功能的入口
- 不出现手机 App 与小程序界面形态（本产品三端均为网页形态）
- 不出现机构端与讲师端的界面元素混入学员端
- 不使用深色模式与高饱和撞色，不使用拟物与 3D 装饰元素

四、本版附加禁止（v0.6.1 范围外，同样不得出现）：
- 不出现「我的订单」「订单查询」「学习记录查看」入口（随下一大版本交付；导航仅「首页／课程／我的课程」）
- 不出现试看标记与试看按钮（试看不提供）
- 不出现附件下载或资料获取入口（附件学员获取随后续版本）
- 不出现优惠券、退款、购物车等交易元素
- 不出现课程审核、下架操作等机构端与讲师端界面

五、输出要求：
1. 先只输出**生图提示词本身**，不要生成图片。
2. 提示词用中文撰写，结构为：画面类型与宽高比 → 页面结构与区块顺序 → 各区块的界面元素与文案 → 整体风格锚定（色值、字体、组件形态）→ 禁止项。
3. 宽高比：桌面端 16:10（1440×900 视口）。
4. 界面文字直接写进提示词（生图模型的文字渲染不可靠，我会在生图后逐处校正）。
5. 先只给我这一张（课程学习页）的提示词，等我确认后再生图；不要提前规划其他页面。
```

## 2. 第二步：生成并迭代核心界面

> 拿到提示词后复制下面这句：

```
请按上面的提示词生成图片。生成后请对照提示词自检：区块是否齐全、色值是否按锚定执行、界面文字是否可读且无英文、是否有被禁止的元素（尤其注意：不得出现我的订单/学习记录查看/试看/附件下载等禁止项）。列出偏差，并给出修正后的提示词。
```

迭代方法：

1. 每次只改一处（区块、色值、文案），避免一次改多项后分不清哪次变动生效。
2. 满意的课程学习页即为**本版风格基准**：本版其余图片都以它为准，不重新定义色板与组件形态。
3. 与项目层主页基准及 v0.5.1 学员端首页、v0.6.0 支付页基准**并检一次**：并排比对字体层次、卡片圆角与色板是否同源，防止跨版本风格漂移；发现漂移以项目层附 A 色值为准修正提示词。
4. 生图必然色偏：图片像素取色仅作参考，**色值以本脚本附 A（引自项目层）为唯一来源**（代码层按附 A 实现）。
5. 出现本版附加禁止所列元素（订单入口、试看标记等）时，直接判为不合格并要求重出，不手动修补。

## 3. 第三步话术：规划本版其余图片并逐张撰写提示词

> 核心界面定稿后复制下面整段：

```
课程学习页已定稿，它现在是本版本的风格基准：色板、字体层次、组件形态一律以它为准，不得改变。

请规划本版本（v0.6.1 交付与学习）其余需要出图的界面，并按覆盖要求逐张撰写生图提示词。

一、覆盖要求（必须全部覆盖，一张图或一组图覆盖一项；认领条目为 R49 我的课程查看、R50 播放凭据获取、R51 学习记录更新）：
1. 学员端（桌面 16:10）：「我的课程」列表页（导航含「首页／课程／我的课程」三项；列表列：课程名、课时总数、已学课时数（如 2／4）、最近学习时间〔未开始标注〕；按最近学习时间倒序；已下架课程带「已下架」角标仍可进入学习）；「我的课程」空态（「还没有课程，去逛逛」＋课程列表入口）；学习页首次进入态（0 已学、无「继续学习」入口，目录全部未学）；学习页无资格提示态（「暂无学习资格，请先购买课程」＋课程详情入口；介绍与目录仍可看）；视频加载失败可重试提示（「视频加载失败，请重试」）；课时不存在提示（「课时不存在」）
2. 机制条目声明：R51 学习记录更新为机制条目——由播放行为同链路触发、无人工操作面、不单独生成界面；其结果经「我的课程」进度摘要（已学数／总数、最近学习时间）与课程目录已学标记呈现（已由上述界面覆盖）
3. 手机形态：本版不新增手机界面（项目层覆盖要求的手机图仅首页与课程详情两项，随对应版本交付；学习页手机适配建议已回池评估）

二、各界面的关键信息点（必须画出来）：
- 我的课程列表：进度摘要口径「已学课时数／课时总数」；从未学习显示「未开始」；已下架角标用辅助色
- 学习页目录：序号＋标题＋已学对勾（成功色）、当前课时高亮（主色浅底）、「继续学习：第 N 课」入口
- 无资格态：播放区替换为提示卡（不可播放），目录与介绍区保留可看
- 播放器为网页视频控件形态（进度条可用点缀色），不得出现业务按钮

三、宽高比：全部为桌面端 16:10（1440×900）。学员端为 PC 网页形态。

四、输出顺序要求：
1. 先给出**图片清单**：每张图一行（图名／所属端／作用／宽高比），并说明总数与顺序理由，等我确认。
2. 确认后再**逐张输出生图提示词**（一次一张，结构同第一张：画面类型与宽高比 → 页面结构 → 元素与文案 → 风格锚定 → 禁止项），不要一次输出全部。
3. 全部遵循第一张的风格锚定与通用禁止＋本版附加禁止；不得引入新的色值。
```

## 4. 第四步：批量生成

> 清单确认后，逐张复制：

```
按这张的提示词生成图片。生成后自检并列出偏差：区块是否齐全、色值是否与风格锚定一致、文字是否全中文、是否出现被禁止的元素（含本版附加禁止：我的订单/学习记录查看/试看/附件下载等不得出现）；有偏差时给出修正后的提示词。
```

单张迭代方法：只改一句话（改区块／改色／改文案），每次生成后与本版第一张（课程学习页）并排比对风格一致性；连续两次仍偏离时，回到提示词层面重写该区块描述，而不是继续叠加修正语。

## 5. 收尾：回填归档

1. 把每张图的最终结果与偏差填写到**附 B 生图回填区**。
2. 若生图过程中对色值做了微调（只允许微调明度），**同步更新项目层脚本附 A**（唯一来源）与本脚本附 A，确保代码层与设计同源；本脚本不自定新色值。
3. 界面文案以本版 PRD 与术语表的用词为准（学员、我的课程、继续学习、课时目录等称谓逐字沿用）：生图模型的界面文字不可靠，出图后逐处校正；本版不出现的业务概念（我的订单、学习记录查看页、试看、附件下载）如混入图中，判为不合格重出。
4. 本版新增界面的要素不回写项目层脚本（风格变更才回写项目层）。

## 附注 其他生图模型的差异

对无对话记忆的模型（如即梦等）：把本脚本第 1 步话术中的「风格锚定」「通用禁止」「本版附加禁止」三段原文，连同 GPT 已写好的单张生图提示词，拼成一段一次性提交；每张图都重复带上风格锚定，避免模型自行改色。第 3 步的「让 GPT 规划清单」改为人工按覆盖要求逐项对照，仍遵守「数量与顺序由规划结果说明、不写死」的原则。
