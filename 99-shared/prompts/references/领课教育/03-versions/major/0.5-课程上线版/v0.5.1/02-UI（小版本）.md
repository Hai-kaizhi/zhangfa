## 1. 第一步话术：让 GPT 产出本版核心界面的生图提示词

> 复制下面整段发给 GPT（资料已在上文给过）：

```
你是资深 UI/UX 设计师，精通中文界面设计与生图提示词撰写。

我在做一个在线教育系统（三端网页：学员端、讲师端、机构端管理后台）的课程门户版本。请先通读我给你的资料（小版本 PRD、项目层 UI 脚本、术语表），只做理解，不要生成任何图片。

任务：为这个产品的【学员端首页】撰写第一张图的生图提示词。

一、这张图必须包含的元素（学员端首页）：
- 顶部：站点名称、主导航（仅「首页」「课程」两项）、搜索框、登录／注册入口（未登录态）
- 推荐区：已发布课程的推荐卡片组（每张卡片：课程名称、讲师名、价格——0 元显示「免费」；无封面图，以课程名称首字或简洁占位图形呈现卡片视觉主体）
- 分类区：课程分类入口（一级／二级分类导航）
- 页脚：站点基础信息与帮助入口
- 按 6～8 张课程卡片、有分类入口的状态画；本版本首页不出现「我的课程」「我的订单」「继续学习」等入口

二、全局风格锚定（必须严格遵守，不得自行改色）：
- 产品气质：可信、清晰、有学习氛围的在线教育平台；界面克制、信息层级清楚，不花哨
- 主色（品牌色）：#0056D2（用于主按钮、选中态、链接与关键强调）
- 副色／点缀色：#03C7E8（仅用于进度条、数据可视化与轻量强调，不用于大面积背景）
- 中性色：页面底 #F5F6F8；卡片与内容底 #FFFFFF；标题文字 #1C1D1F；正文 #454545；辅助文字 #707070；分隔线与描边 #E1DDDB
- 语义色：成功 #0D7D4D；警告 #D6B600；危险 #AB0D02；信息 #00688D
- 色板配比：中性色承担 80% 以上面积，主色用于操作与强调，点缀色占比不超过 5%
- 字体：中文无衬线（PingFang SC／Microsoft YaHei／Noto Sans CJK SC），数字与拉丁用 Inter；标题与正文层次靠字重与字号，不靠颜色堆叠
- 组件形态：卡片圆角 8px、按钮圆角 6px、输入框圆角 6px；描边 1px；阴影克制（仅用于浮层），不用大面积渐变色与发光效果
- 无障碍：正文文字与背景对比度不低于 4.5:1；不使用在白底上对比不足的浅色文字

三、通用禁止（任何一张图都不允许出现）：
- 全中文界面（不得出现英文界面文案与英文占位词）；只允许极少量数字与金额
- 不出现第三方品牌标识、平台水印、二维码、联系方式
- 不出现真实人物照片、真实机构名与真实版权课程名（本项目为模拟案例，课程与讲师名为虚构）
- 不出现直播、在线考试与题库、任务打卡与积分证书、社区问答与博文等本期不做功能的入口
- 不出现手机 App 与小程序界面形态（本产品三端均为网页形态）
- 不出现机构端与讲师端的界面元素混入学员端
- 不使用深色模式与高饱和撞色，不使用拟物与 3D 装饰元素

四、本版附加禁止（v0.5.1 范围外，同样不得出现）：
- 不出现购买、下单、支付、购物车、优惠券、试看等交易元素与按钮（随下一大版本交付）
- 不出现「我的课程」「继续学习」「学习记录」「我的订单」入口（随后续版本交付；导航仅「首页」「课程」）
- 不出现课程审核界面与送审入口（上一批已交付，本版不重出）
- 不出现课程封面图上传或封面上传入口（本版不做封面）
- 不出现人工推荐位配置界面

五、输出要求：
1. 先只输出**生图提示词本身**，不要生成图片。
2. 提示词用中文撰写，结构为：画面类型与宽高比 → 页面结构与区块顺序 → 各区块的界面元素与文案 → 整体风格锚定（色值、字体、组件形态）→ 禁止项。
3. 宽高比：桌面端 16:10（1440×900 视口）。
4. 界面文字直接写进提示词（生图模型的文字渲染不可靠，我会在生图后逐处校正）。
5. 先只给我这一张（学员端首页）的提示词，等我确认后再生图；不要提前规划其他页面。
```

## 2. 第二步：生成并迭代核心界面

> 拿到提示词后复制下面这句：

```
请按上面的提示词生成图片。生成后请对照提示词自检：区块是否齐全、色值是否按锚定执行、界面文字是否可读且无英文、是否有被禁止的元素（尤其注意：导航仅「首页／课程」，不得出现我的课程／我的订单／继续学习／购买元素）。列出偏差，并给出修正后的提示词。
```

迭代方法：

1. 每次只改一处（区块、色值、文案），避免一次改多项后分不清哪次变动生效。
2. 满意的首页即为**本版风格基准**：本版其余图片都以它为准，不重新定义色板与组件形态。
3. 与项目层主页基准**并检一次**：本项目层第一张图即学员端主页，逐区块比对同源度（导航、卡片形态、色板）；发现漂移以项目层附 A 色值为准修正提示词。
4. 生图必然色偏：图片像素取色仅作参考，**色值以本脚本附 A（引自项目层）为唯一来源**（代码层按附 A 实现）。
5. 出现本版附加禁止所列元素（交易元素、后续版本入口等）时，直接判为不合格并要求重出，不手动修补。

## 3. 第三步话术：规划本版其余图片并逐张撰写提示词

> 核心界面定稿后复制下面整段：

```
学员端首页已定稿，它现在是本版本的风格基准：色板、字体层次、组件形态一律以它为准，不得改变。

请规划本版本（v0.5.1 对外展示与下架）其余需要出图的界面，并按覆盖要求逐张撰写生图提示词。

一、覆盖要求（必须全部覆盖，一张图或一组图覆盖一项；认领条目为 R40 首页浏览、R41 分类浏览与搜索、R42 课程详情查看、R43 课程下架）：
1. 学员端（桌面 16:10）：首页空态（无已发布课程时推荐区「暂无课程」）；分类课程列表页（分类导航＋课程卡片列表＋分页 10／20／50）；搜索结果页（关键词与结果数提示，可与分类列表合并一张说明或单独出图，由你判断）；课程详情页（课程编号、名称、介绍、价格〔0 元显示「免费」〕、讲师介绍区、课程目录——序号＋课时标题清单、底部「购买功能即将开放」提示，无购买按钮）；空结果与异常态（「该分类暂无课程」「未找到相关课程」「课程不存在」提示页——未发布与已下架课程详情均走此口径）
2. 学员端（手机 9:19.5，390×844）：首页与课程详情两项的适配形态（承接项目层覆盖要求，验证手机浏览器呈现）
3. 机构端（桌面 16:10）：课程列表的「下架」操作视角（已发布课程行内「下架」按钮，机构管理员／机构运营人员视角）；下架确认弹窗（下架原因输入 5～200 字＋「确认下架」「取消」）；下架拦截提示（「仅已发布课程可下架」「请填写 5～200 字下架原因」「无下架权限」「课程状态已变更，请刷新列表」）；下架成功后列表状态「已下架」
4. 机制条目声明：本版四条认领条目均有人工操作面（R40～R42 学员端浏览、R43 机构端操作），无「无界面、不生成图」的机制条目

二、各界面的关键信息点（必须画出来）：
- 课程卡片：课程名称、讲师名、价格（0 元＝「免费」）；无封面图（占位图形或名称首字）
- 详情页目录：仅课时清单（序号＋标题），不出现附件清单与播放控件（附件获取与播放随下一大版本）
- 详情页不出现购买、试看按钮；底部「购买功能即将开放」提示条
- 下架弹窗：危险色强调（终态操作）、原因必填输入
- 学员端任何界面不得出现未发布课程（状态过滤后呈现）

三、宽高比：桌面端一律 16:10（1440×900）；学员端手机图 9:19.5（390×844）。机构端为 PC 网页形态，不做手机形态。

四、输出顺序要求：
1. 先给出**图片清单**：每张图一行（图名／所属端／作用／宽高比），并说明总数与顺序理由，等我确认。
2. 确认后再**逐张输出生图提示词**（一次一张，结构同第一张：画面类型与宽高比 → 页面结构 → 元素与文案 → 风格锚定 → 禁止项），不要一次输出全部。
3. 全部遵循第一张的风格锚定与通用禁止＋本版附加禁止；不得引入新的色值。
```

## 4. 第四步：批量生成

> 清单确认后，逐张复制：

```
按这张的提示词生成图片。生成后自检并列出偏差：区块是否齐全、色值是否与风格锚定一致、文字是否全中文、是否出现被禁止的元素（含本版附加禁止：交易元素／我的课程等后续入口／播放控件不得出现）；有偏差时给出修正后的提示词。
```

单张迭代方法：只改一句话（改区块／改色／改文案），每次生成后与本版第一张（学员端首页）并排比对风格一致性；连续两次仍偏离时，回到提示词层面重写该区块描述，而不是继续叠加修正语。

## 5. 收尾：回填归档

1. 把每张图的最终结果与偏差填写到**附 B 生图回填区**。
2. 若生图过程中对色值做了微调（只允许微调明度），**同步更新项目层脚本附 A**（唯一来源）与本脚本附 A，确保代码层与设计同源；本脚本不自定新色值。
3. 界面文案以本版 PRD 与术语表的用词为准（学员、机构管理员、机构运营人员、课程编号、我的课程不得出现在本版导航、暂无课程等称谓逐字沿用）：生图模型的界面文字不可靠，出图后逐处校正；本版不出现的业务概念（购买、播放、我的订单）如混入图中，判为不合格重出。
4. 本版新增界面的要素不回写项目层脚本（风格变更才回写项目层）。

## 附注 其他生图模型的差异

对无对话记忆的模型（如即梦等）：把本脚本第 1 步话术中的「风格锚定」「通用禁止」「本版附加禁止」三段原文，连同 GPT 已写好的单张生图提示词，拼成一段一次性提交；每张图都重复带上风格锚定，避免模型自行改色。第 3 步的「让 GPT 规划清单」改为人工按覆盖要求逐项对照，仍遵守「数量与顺序由规划结果说明、不写死」的原则。
