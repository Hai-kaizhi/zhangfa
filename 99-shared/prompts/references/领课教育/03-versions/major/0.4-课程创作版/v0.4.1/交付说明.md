## 3. 运行方式

（文档范本演练口径的模拟叙述，随真实代码交付后按此执行）

1. 数据初始化：MySQL 依次执行 `sql/v0.4.1/course_lesson.sql`、`sql/v0.4.1/course_attachment.sql` 建两张表（既有库执行增量脚本）；上传待处理记录随课程模块建表脚本一并初始化。
2. 外部服务：视频点播与对象存储服务商账号配置就绪（0.2 定案并交付对接参数），站点配置中 `media_config` 的 `video`／`storage` 参数通过连通性校验后，媒体接入模块可正常收发。
3. 后端：Spring Boot 可执行服务启动（课程模块与媒体接入模块随模块化单体一并加载）。
4. 前端：讲师端 `web-teacher` 以 Vite 构建／启动（本版无机构端与学员端界面变更）；主题令牌按项目层 UI 脚本附 A 落值。
5. 验证路径：以讲师账号进入课程草稿详情，走「新增课时（含 mp4／超限失败分支）→ 上传附件（含格式／超限失败分支）→ 课时排序 → 删除课时与附件 → 复入核对」全链；以第二讲师账号核对全部越权分支按第 2 节证据口径逐条复现。

## 4. 已知限制与待确认

1. 外部存储中的视频与附件本体不随软删除清理（软删除只解除目录／清单呈现）；本体的生命周期管理（清理策略）归开发与运维，待运营口径确认。
2. 上传无断点续传（02 已声明围栏外，建议已回池）；大文件上传中断依赖重试。
3. 已知限制（PRD 第 6 章拍板值随版携带）：课时与附件数量、附件总容量无上限；并发排序以最后保存为准（不做乐观锁）；附件清单不展示大小／格式列。
4. 待确认（沿用 PRD 待议，不影响本版验收）：附件清单是否扩充展示列；断点续传是否立项。
5. 术语表待登记清单已随本版 PRD 第 6 章回报（课时 `title`／`video_ref`，课程附件 `file_name`／`file_ref` 新增，`course_id`／`sort_order`／`deleted_at` 扩展适用对象），以主流程合入为准。
