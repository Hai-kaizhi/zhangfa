## 1. 实现清单（条目｜代码位置｜实现要点）

| 条目 | 代码位置 | 实现要点 |
|---|---|---|
| R1 注册 | 后端：账号与权限模块 `student` 包 `POST /api/student/register`；前端：学员端 `views/register`；数据：`student_account` 表 | 手机号唯一（唯一索引 `mobile` 兜底＋前置查询提示）；密码 8～20 位字母＋数字规则校验；昵称未填生成「学员＋编号后 4 位」；注册成功生成学员编号（`ST`＋8 位序号）、状态 `normal` 并自动登录 |
| R2 登录与退出 | 后端：`POST /api/student/login`、`POST /api/student/logout`；前端：学员端 `views/login` 与登录后头部退出入口；数据：会话存储（Redis） | 凭据校验统一提示「手机号或密码错误」；失败计数按账号维度，连续 5 次锁定 15 分钟，成功登录清零；会话有效期 7 天；退出即删除会话 |
| R3 个人资料维护 | 后端：`GET/PUT /api/student/profile`；前端：个人中心 `views/profile` | 仅本人可访问（身份上下文取数，无他人资料入口）；手机号与学员编号只读展示；昵称必填 ≤20 字符、邮箱选填格式校验；保存即时生效 |
| R4 密码修改 | 后端：`PUT /api/student/password`；前端：个人中心 `views/password` | 原密码校验；新密码 8～20 位字母＋数字且不得与原密码相同；修改成功后删除该账号全部会话并跳转登录页；原密码错误不累计登录锁定计数 |
| R5 登录鉴权与按端隔离 | 后端：账号与权限模块鉴权过滤器（入口层）＋身份上下文工具 | 每次请求解析登录态（存在且未过期）→建立身份上下文→按端一致性校验；学员端登录态访问机构端接口拒绝（403 无权限）；缺失／过期／伪造登录态一律按未登录处理 |

数据落地：`student_account` 表字段 `id`／`no`／`mobile`／`password`（不可逆加密）／`nickname`／`email`／`status`／`created_at`／`updated_at`，命名与 PRD 第 5 章及术语表逐字一致；会话存 Redis（键含账号标识与端标识，值含 `account_id`／`side=student`／`expire_at`）。

## 3. 运行方式

- 后端：账号与权限模块随单后端应用启动（技术文档：Spring Boot 单体，连 MySQL 与 Redis；版本以依赖锁文件为准）；执行数据库迁移脚本建 `student_account` 表与 `mobile` 唯一索引。

- 验证路径：注册 → 自动登录进入个人中心 → 维护资料 → 修改密码重新登录 → 退出（即 PRD 旅程一遍）。
