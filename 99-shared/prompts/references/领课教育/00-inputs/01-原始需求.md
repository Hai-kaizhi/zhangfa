# 原始需求

我们要自建一套在线教育系统（暂定名「领课教育」）：让机构开课、讲师授课、学员选课学习都在网上完成，招生、交费和学习记录都留在同一个系统里。参照开源项目领课教育（roncoo-education）：各行业适用的在线教育系统，帮个人或企业搭建轻量级在线教育平台。

给谁用：学员在门户浏览搜索课程、下单支付、在线学习，查看学习记录与订单；讲师入驻后维护个人介绍与课程、查看收益；机构的运营管理人员在网页后台做配置、审核、订单和数据管理。

解决什么问题：机构和老师想开线上课，自研成本高、周期长；视频与资料缺统一的存放与播放方式；报名、交费、学习和记录散在线下，人和进度跟不住；课卖得怎么样、谁在学，没数据可看。

核心场景与业务闭环：机构在后台配好站点与课程分类 → 讲师入驻、通过审核 → 讲师建课、上传课时与附件、提交上架 → 机构审核后发布 → 学员在门户找到课程，看讲师与目录、下单支付 → 学员在我的课程里播放、留下学习记录 → 订单汇入后台，机构与讲师各自查看订单与收益 → 用报表复盘，调整课程与招生。

范围与偏好：
- 要三个端：学员端（门户，网页为主、手机可用，优先）＋讲师端（工作台）＋机构端（PC 网页后台）。
- 学员端必须有：首页与推荐位、分类与搜索、课程详情（讲师、课程介绍、目录）、下单支付、在线播放与我的课程、学习记录、订单查询、资料与密码。
- 讲师端必须有：入驻申请、讲师信息、课程管理（新增／修改／提交审核）、收益。
- 机构端必须有：多角色权限、站点与第三方参数配置、讲师入驻审核、课程审核、分类管理、订单管理与统计、登录控制（防共号）。
- 课程视频与资料要能对接多家服务商，方便替换。
- 本期明确不做：直播课、在线考试与题库、任务打卡与积分证书、社区问答与博文、原生 App 和小程序；不做多租户，按单机构自建自营设计。
