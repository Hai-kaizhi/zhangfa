**与技术文档分包的关系**：本目录七个业务模块与技术文档的七个业务分包一一对应；技术文档中的「媒体接入模块」为纯技术基建（视频与存储服务商适配），不独立成业务模块，其边界见《04C-00-模块总览.md》第 1.2 节的映射说明。

**未实现声明**：本目录为项目级模块设计，只写跨版本稳定的机制、规则与契约；页面交互、字段、时限阈值与授权到人等本版本变量留在小版本 PRD 与开发阶段落地，本目录不含实现代码。

**维护记录**：本目录文档随项目级基线更新；命名变更见《[术语表（项目）](../术语表.md)》的变更记录，项目进度见项目根 `README.md`（本目录不另设维护记录文件）。
