# 章法管理流程图：生图说明

此文件记录 README 流程图的生成与校正话术，供后续维护使用。

- 图片：[章法管理流程.png](./章法管理流程.png)
- 用途：README 开头的中文管理流程总览。
- 执行方式：内置 imagegen 工具；先生成，再进行两轮箭头校正。
- 流程依据：[开发路径与节点清单](../../99-shared/prompts/00-开发路径与节点清单.md)、[项目总览](../../项目总览.md)。
- 最终表达：项目级 → 大版本 → 需求池 → 小版本；保留并行分支、开发二选一、按需标识和发布五动作。返工与下一版本安排使用文字提示。
