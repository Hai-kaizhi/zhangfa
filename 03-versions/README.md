# 03-versions — 大版本目录与小版本归档

当前无活动版本，本目录为空模板态。目录结构由提示词在流程中创建：

```text
03-versions/major/<版本>-<名称>/          大版本目录（如 0.1-权限基座版）
                ├── 01-PRD（大版本）.md
                ├── 02-开发顺序与需求拆解（大版本）.md
                └── v<X.Y.Z>/             小版本发布归档（PRD、UI、交付说明、归档说明）
```

- 大版本目录名＝`<版本>-<名称>`，由大版本 01 PRD 提示词创建。
- 小版本开发中产物在 `04-workspace/v<X.Y.Z>/`；发布时由小版本 05 提示词归档至所属大版本目录下。
- 完整示例见[示范项目](../99-shared/prompts/references/README.md)各项目的同名目录。
