# 02-requirement-pool — 需求池与台账

当前项目尚未立项，本目录为空模板态；台账文件不预置空文档，由提示词在首次使用时创建：

| 文件 | 创建时机 | 结构口径 |
|---|---|---|
| `需求池.md` | 首次入池（[需求池提示词](../99-shared/prompts/02-requirement-pool/01-提示词-需求池运营（需求池）.md)） | 单表制：一句定位＋活跃需求总表（待规划／已认领／搁置）；逐字固定模板 |
| `版本注册表.md` | 首次小版本认领（小版本 01 PRD 提示词） | 版本号｜立项时点｜认领条目数｜状态（开发中／已发布） |
| `发布日志.md` | 首次入池／认领／发布时（相应提示词） | 三节：①发布记录（一行一版）②需求归档明细（逐条）③池变更记录（只增流水） |

完整示例见[示范项目](../99-shared/prompts/references/README.md)各项目的同名目录。
